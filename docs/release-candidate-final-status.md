# Release Candidate — Final Status

**Status: PARTIAL.** نواة Nawa AI والتحليلات المحكومة متاحة للتجارة والمخزون والتوزيع والتصنيع والمالية وHR، مع اشتراك خادمي وسياق معزول ومخرجات منظمة وتدقيق وتعطل آمن. توجد الآن واجهة اختيار مجال تحليل متعددة اللغات ورسوم تفاعلية للتجارة والمخزون، كما تغطي اختبارات مباشرة المخرجات المنظمة والتعطل الآمن. اجتازت حزمة الانحدار **69 ملف اختبار و141 اختباراً**، وفحص الأنواع والتحقق المرئي لمساحة العمل.

تظل الحالة PARTIAL إلى أن تكتمل خطة النسخ والاستعادة التشغيلية الخاصة بالإطلاق وتدقيق الواجهة على سيناريوهات صلاحيات المستخدم الفعلية. لا تنفذ Nawa AI أي إجراء تشغيلي أو مالي أو HR تلقائياً؛ جميع الإجراءات تحتاج موافقة بشرية صريحة.
