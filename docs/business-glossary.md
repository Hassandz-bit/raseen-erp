# معجم Nawa ERP التشغيلي

| العربية | Français | English | الاستخدام |
|---|---|---|---|
| المؤسسة | Organisation | Organization | سياق العزل والاشتراك |
| المخزن | Entrepôt | Warehouse | موقع الرصيد والمخزون |
| الدفعة | Lot | Batch | كمية ذات تكلفة وصلاحية |
| الأقرب انتهاءً أولاً | Premier expiré, premier sorti | First Expiry, First Out | قاعدة صرف المخزون |
| فاتورة المبيعات | Facture de vente | Sales invoice | مستند البيع والصرف |
| أمر الشراء | Bon de commande | Purchase order | مستند التوريد والاستلام |
| الجرد | Inventaire | Inventory count | مقارنة الرصيد الفعلي والنظامي |
| سعر الصرف | Taux de change | Exchange rate | سجل تاريخي مقيد بعملة الأساس |
| العملة الأساسية | Devise de base | Base currency | مرجع المؤسسة المالي |
| تنبيه المؤسسة | Alerte de l’organisation | Organization alert | إشعار تشغيلي ضمن المؤسسة |
| الوحدة والاشتراك | Module et abonnement | Module & subscription | تفعيل القدرة التشغيلية |
| معاينة الطباعة | Aperçu avant impression | Print preview | مستند قابل للحفظ PDF من المتصفح |

> يعتمد القاموس على مفردات واجهة Nawa ERP المركزية، ويُستخدم مرجعاً عند نقل النصوص التشغيلية الموروثة إلى الترجمة الثلاثية.
