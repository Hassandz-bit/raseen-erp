# RASEEN ERP — V01 Simulation Storyboard

> **نسخة المراجعة التالية تحاكي مشكلة تشغيلية وحلاً رقمياً؛ المشاهد البشرية والمتاجر والشاحنات والسلع مولّدة لشرح الفكرة، وليست تصويراً لعملاء حقيقيين أو بيانات تشغيلية فعلية.**

## القرار الإبداعي

الفيديو الرئيسي أفقي 16:9 بدقة 1920×1080 ومدته المستهدفة 100 ثانية. أسلوبه **دراما تشغيلية واقعية راقية**: بداية أكثر دفئاً وفوضوية في متجر ومستودع، ثم انتقال تدريجي إلى كحلي رصين وذهبي منظم بعد ظهور الحل. لا توجد موسيقى أو غناء؛ الصوت هو تعليق عربي رجالي حماسي متصل مع أصوات بيئية خفيفة فقط، مثل طابعة إيصالات وتنبيه ماسح ومؤشر شاحنة بعيد.

| العنصر المتكرر | الوصف الثابت |
|---|---|
| مدير المتجر | رجل عربي في أواخر الثلاثينات، شعر داكن قصير، قميص كحلي بأكمام مطوية، ساعة فضية؛ حركته عملية وسريعة في المشكلة ثم هادئة وواثقة في الحل. |
| مسؤولة المخزون | امرأة عربية في أوائل الثلاثينات، حجاب بيج وصديرية عمل كحلية؛ تمسك ماسح باركود أو جهازاً لوحياً عند الحاجة. |
| السائق | رجل عربي في أوائل الثلاثينات، سترة توصيل كحلية بلا شعارات، يقود شاحنة توزيع بيضاء نظيفة بتفاصيل ذهبية مجردة. |
| بيئة المتجر | متجر متوسط حديث فيه رفوف منظمة ومنتجات عامة بلا علامات تجارية أو نصوص مقروءة. |
| بيئة المستودع | رفوف مخزون وصناديق كرتونية وملصقات تجريدية غير مقروءة؛ لا توجد بيانات أو شعارات حقيقية. |
| الهوية البصرية | كحلي عميق، ذهبي مطفأ، أبيض دافئ، إضاءة واقعية ناعمة، وتحول مرئي من أصفر فوضوي إلى كحلي/ذهبي منظم. |
