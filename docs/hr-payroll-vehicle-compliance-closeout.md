# تقرير تدقيق HR والرواتب وامتثال وثائق المركبات

## الحالة

**PARTIAL.** تستند الدفعة إلى نقطة الأساس `50c6e60`، وتضم ترحيلات `0030` لتاريخ بداية وثائق المركبة و`0031` لخصم الغياب اليومي القابل للتهيئة و`0032` لتاريخ حدث العمولة. تم إصلاح فجوات تشغيلية مؤكدة دون إعادة بناء الوحدات القائمة.

| المجال | الحالة | التنفيذ المثبت |
|---|---|---|
| خصم الغياب | DONE | يضبط العقد `absenceDeductionPerDay` صراحةً، ويحسب المحرك الأيام المسجلة بحالة `absent` داخل فترة الرواتب فقط، ويثبت الأيام والمبلغ في اللقطة. |
| السلف والاسترداد | DONE | لا يسترد إلا ما صُرف، ويحدّث الرصيد والحالة عند دفع فترة الرواتب. |
| قسيمة الراتب | DONE | قسيمة الموظف الخاصة تعرض في البوابة الذاتية وتدعم تنزيل PDF والطباعة من اللقطة المحفوظة. |
| عملة وحساب الموظف | DONE | تستخدم السلفة الذاتية عملة الراتب الفعلية بدلاً من قيمة ثابتة، ويدعم ملف الموظف مرجع حساب بنكي لا يظهر في البوابة العامة. |
| التقارير | PARTIAL | سجل الرواتب وتصدير Excel وقسيمة PDF متاحة، وتقبل تقارير HR مرشحات الفرع والقسم خادمياً؛ تبقى القوالب القانونية الخاصة بدولة مؤجلة. |
| العمولات | PARTIAL | قواعد وقيود مصدر فريدة وتاريخ حدث صريح موجودة، لذلك تدخل العمولة في فترة وقوعها لا تاريخ إنشائها. يبقى الربط التلقائي المتخصص بأحداث البيع والتحصيل مؤجلاً لغياب تعيين موظف موثوق في تلك المستندات. |
| نطاق HR | PARTIAL | سرية الأجور وصلاحيات الموظف والمدير المباشر حمايات خادمية، وتطبق مرشحات الفرع والقسم على تقارير HR. تعميم نطاق البيانات على كل إجراء HR يحتاج طبقة صلاحيات نطاق مستقلة. |
| وثائق المركبة | DONE | ينشئ نموذج المركبة وثيقتي تأمين ومراقبة تقنية بتواريخ بداية ونهاية، ويرفض التاريخ المعكوس أو الناقص. يفحص مركز التوزيع الوثائق المنتهية أو القريبة خلال 30 يوماً ويمنع تكرار التنبيه غير المقروء. |

## التحقق

| التحقق | النتيجة |
|---|---|
| `pnpm check` | ناجح. |
| `pnpm lint` | ناجح بلا أخطاء؛ التحذيرات الموروثة فقط خارج هذه الدفعة. |
| `pnpm build` | ناجح؛ تحذير حجم الحزمة غير مانع. |
| `pnpm test` | **65 ملف اختبار و133 اختباراً ناجحاً**. |
| اختبار الرواتب | يغطي الغياب واللقطة والاعتماد والترحيل والدفع واسترداد السلفة وعمولة الحدث داخل الفترة فقط. |
| اختبار التوزيع | يغطي GPS، ووثيقتي التأمين والمراقبة التقنية، وعزل المؤسسة وحركات التحميل. |
| اختبار القسيمة | يغطي تنزيل PDF والطباعة لقسيمة الموظف المعزولة. |

## القيود المتبقية

لا يشمل الإغلاق محرك قوانين أو ضرائب دولة، جهاز بصمة، ربطاً تلقائياً خاصاً بالعمولات، أو نطاق فرع/قسم موحداً لكل عقد HR. هذه عناصر توسعة مستقلة وليست أخطاء في الدورة الحالية.
