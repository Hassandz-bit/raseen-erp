# تقرير إغلاق مرحلة المالية والمحاسبة

## النطاق المنجز

اكتملت نواة المحاسبة متعددة المؤسسات في Nawa ERP، بما يشمل دليل حسابات هرمي افتراضي قابل للتهيئة، الدفاتر، السنوات والفترات المالية، القيود وأسطرها، المطابقات المحاسبية، وقيود الترحيل والعكس. تُنشأ القيود التشغيلية من أحداث المبيعات والمشتريات والتحصيل وتسويات المخزون والتصنيع والتوزيع ومدفوعات الموردين؛ ولا تعتمد أي قاعدة ترحيل على معرّفات حسابات ثابتة.

| المجال | الضبط المنفذ |
|---|---|
| عزل المؤسسة | يُضم `organizationId` إلى كل استعلام وكل فهرس منع تكرار متعلق بالمصدر أو الحركة. |
| منع التكرار | فهرس فريد للقيد المصدر، ومفاتيح idempotency لحركات الخزينة والتحويلات ومدفوعات الموردين. |
| الحوكمة | لا يُعدّل القيد المرحّل؛ يصحح بقيد عكس مرجعي ومدقق. |
| إقفال الفترات | يمنع ترحيل المسودة أو العكس إلى فترة مغلقة أو محجوبة. |
| العملات | يحتفظ القيد بعملة المستند وسعر الصرف الملتقط، وتُوازن الأسطر في عملة القيد. |

## الطبقة التشغيلية والخزينة

يغطي الترحيل الآلي فواتير المبيعات وتكلفة المبيعات والضرائب الأساسية، أوامر الشراء المستلمة، تحصيلات العملاء، صرف المواد ومخرجات الإنتاج، تسويات المخزون، تحصيلات ومصروفات التوزيع، ومدفوعات الموردين. أضيفت الصناديق والحسابات البنكية وحركاتها والتحويلات بين حسابات الخزينة، إلى جانب تقريري أعمار الذمم المدينة والدائنة بالفئات: حالي، 1–30، 31–60، 61–90، وأكثر من 90 يوماً.

> لا تعني المطابقات الافتراضية تبنّي مخطط قانوني لبلد بعينه؛ فهي نقطة بداية عامة، ويمكن للمؤسسة تعديل الربط من إعدادات المطابقات قبل اعتماد العمليات التشغيلية.

## واجهة مركز المالية

أضيف مسار `/finance` إلى التنقل الرئيس مع تبويبات نظرة عامة، دليل الحسابات، القيود، الذمم، الخزينة، والتقارير. تعرض الصفحة حالات التحميل والفراغ عبر استعلامات tRPC المقيدة بالمؤسسة، وتتيح تهيئة نواة المالية للمالك، وتصدير الملخص المرئي بصيغة Excel متوافقة، والطباعة أو الحفظ بصيغة PDF من المتصفح.

## التحقق

| التحقق | النتيجة |
|---|---|
| فحص الأنواع `pnpm check` | ناجح |
| اختبار سياسة القيود | ناجح: اختباران |
| اختبار تكامل نواة المالية | ناجح: اختباران، ويغطي التوازن والعكس ومنع التكرار وقفل الفترة والعزل |
| اختبار تكامل الخزينة | ناجح: اختبار واحد، ويغطي التحويل ومنع التكرار والرصيد وأعمار الذمم |
| حزمة الانحدار `pnpm test` | ناجحة: 57 ملف اختبار و122 اختباراً |
| فحص بصري لمركز المالية | ناجح على مسار `/finance` بواجهة RTL |

## القيود التشغيلية المعروفة

يبقى بناء الإنتاج للإصدار النهائي مقيداً بحد موارد بيئة البناء، وهو قيد بيئي معروف سابقاً؛ لذلك استُخدم فحص الأنواع، واختبارات التكامل، وحزمة الانحدار، والتحقق البصري لتأكيد سلامة التغييرات.
