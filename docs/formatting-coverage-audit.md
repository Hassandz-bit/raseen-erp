# جرد تغطية التنسيق المؤسسي

## النتيجة

تستخدم واجهات الإنتاج ومسارات التصدير النشطة منسقات المؤسسة المركزية في `client/src/lib/formatting.ts`. وتشمل هذه المنسقات العملة والرقم والنسبة المئوية والتاريخ والوقت وفق إعدادات المؤسسة المخزنة، بما فيها المنطقة الزمنية ونمط الأرقام والفواصل.

| المسار | التغطية | دليل الاختبار |
|---|---|---|
| لوحة التحكم ومساحة العمل | بطاقات مالية، مؤشرات المخزون، نسب الاتجاهات وملخصات التشغيل | `FinancialSummaryCards.dom.test.tsx` و`InsightsPanel.test.tsx` |
| العرض التشغيلي للوحدات | مبالغ السجلات وفواتير المبيعات وكميات المخزون | `ModuleView.test.tsx` و`formatting.test.ts` |
| سجل أسعار الصرف | العملة والرقم والتاريخ في الشاشة وExcel وPDF، مع المرشحات | `ExchangeRatesPanel.test.tsx` و`exchangeRateExport.test.ts` |
| ملخص مساحة العمل | CSV مقتبس بأمان وبقيم مالية ورقمية منسقة | `workspaceSummaryExport.test.ts` |
| الطباعة والمعاينة | اتجاه المستند، الخط، الحجم، أبعاد الورق وتنزيل PDF | `documentPreviewExport.test.ts` و`documentPreviewPdf.dom.test.tsx` |

## الاستثناءات المقبولة

لم تُعثر قيم إنتاجية خام متبقية خارج المسارات أعلاه. الاستخدامات المتبقية لصيغ `Intl` أو قيم عرض معيارية محصورة في مكونات UI عامة مثل التقويم والرسوم البيانية، أو في ملفات الاختبار، أو في سياق اللغة الذي يمثل طبقة التنسيق المركزية نفسها. لا تمثل هذه الاستثناءات بيانات أعمال معروضة أو تصديراً مؤسسياً.

> عند إنشاء تقرير أو تصدير جديد، يجب تمرير تفضيلات المؤسسة إلى helpers نفسها وإضافة اختبار يثبت أن الناتج لا يستخدم تاريخ ISO أو رقماً أو مبلغاً خاماً.
