# تدقيق فجوات المالية والمحاسبة

## نقطة الأساس

نقطة أساس التصنيع المغلق هي `83ab085`، بينما نقطة الاستقرار الفعلية الحالية للمالية والمحاسبة هي `8c85c0e3`. تعتمد أعمال الإكمال على الأخيرة، ولا تعيد بناء التصنيع أو التجارة والمخزون أو التوزيع أو تطبيق السائق أو B2B أو الذكاء الاصطناعي.

## ما هو منفذ بالفعل

تتوفر نواة دليل الحسابات الهرمي، الدفاتر، الفترات، القيود المتوازنة، العكس المدقق، عزل المؤسسة، ومطابقات الحسابات. كما تتوفر قواعد ترحيل تلقائية للأحداث التشغيلية الأساسية، وخزينة أولية، وتحويلات ومدفوعات موردين، وتقارير أعمار الذمم، وواجهة مركز المالية متعددة اللغات.

## الفجوات المؤكدة القابلة للتنفيذ

| المجال | الحالة الحالية | الإكمال المطلوب |
|---|---|---|
| التقارير النظامية | أرصدة فردية وقائمة قيود فقط | الأستاذ العام، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، والتدفق النقدي من القيود المرحّلة. |
| المصالحات | حركات خزينة فقط | أساس تسوية بنك وصندوق بحالة وتفاصيل ومطابقة وفروقات وسجل تدقيق. |
| إقفال الفترة | منع الترحيل في الفترات المغلقة | إجراءات إغلاق وإعادة فتح محكومة بسبب وتدقيق. |
| الأبعاد | حقول branch وcostCenter جاهزة في السطر | كيان مركز تكلفة اختياري وربط انتقائي به ومراعاة العزل. |
| الموازنة | حد شهري في المؤسسة فقط | ميزانيات حسب الحساب والفترة والفرع/المركز، ومقارنة الفعلي من القيود. |
| الواجهة والتصدير | تبويبات مركز أولية وتصدير ملخص القيود | تبويبات التقارير والمصالحات والميزانية مع تصدير جداول التقرير. |

## حدود مقصودة لهذه الدفعة

لا يشمل الإكمال تكامل واجهات البنوك، أو ضرائب قانونية حسب دولة، أو توحيد شركات، أو AI، أو نظام HR موسع. تبقى فروق الصرف غير المحققة مؤجلة، أما فرق الصرف المحقق فيحتاج حدث تسوية فاتورة بعملة أجنبية لا توفره العقود التشغيلية الحالية بصورة كافية، ولذلك لن يُختلق مسار موازٍ له.
