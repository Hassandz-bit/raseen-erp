# V01 Production Blueprint — ما هي رصين؟

## التعريفات العالمية

| العنصر | التعريف المعتمد |
|---|---|
| الطابع البصري | فيديو منتج SaaS مؤسسي سينمائي؛ كحلي عميق، ذهبي RASEEN، أسطح زجاجية هادئة، ضوء حافّة ذهبي محدود، حركة دقيقة غير استعراضية |
| الواجهات | لقطات حقيقية من RASEEN ERP فقط؛ لا تُنشأ واجهات أو قوائم غير موجودة |
| العناصر المتكررة | أيقونة R الذهبية الرسمية، شعار RASEEN ERP، شبكة منظومة ذهبية رفيعة، بطاقات عمليات مجردة بلا بيانات حقيقية |
| الراوي | `Rasalgethi`، صوت رجالي معلوماتي دافئ، العربية الفصحى الحديثة، سرعة طبيعية هادئة |
| اللغة | `ar-001`؛ تكتب كلمات RASEEN ERP بوضوح عند الحاجة |
| الصوت | تعليق فقط، مؤثرات انتقال واجهة قصيرة غير لحنية، صمت مقصود؛ **لا موسيقى ولا غناء ولا إيقاع** |
| الترجمة | عربية، سطران كحد أقصى، في المنطقة الآمنة السفلية، مهيأة كملف SRT مستقل |

## معيار نجاح الحلقة

لا تعتمد الحلقة إلا إذا ظهر الشعار بوضوح، وتطابقت لقطات المنتج مع الواجهة الفعلية، وبقي التعليق مفهوماً من دون موسيقى، وبقيت النصوص داخل المنطقة الآمنة وقراءة العربية مريحة.
