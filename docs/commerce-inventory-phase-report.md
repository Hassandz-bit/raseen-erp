# تقرير مرحلة التجارة والمخزون

## نطاق المرحلة المكتمل

أُنجزت نواة **Commerce & Inventory** ضمن سياق المؤسسة الحالي، مع فرض `organizationId` على المستندات والدفعات والحركات والملخصات. تشمل المرحلة Product Master، العملاء والموردين، المخازن، الدفعات، حركات الرصيد، فواتير المبيعات، أوامر الشراء، التحويلات، والجرد.

> **قرار نطاق صريح:** يقتصر إغلاق هذه المرحلة على التجارة والمخزون. لا يشمل القرار التنفيذي الحالي وحدات التوزيع أو الأسطول أو التصنيع أو الإنتاج أو GPS أو التطبيقات الميدانية؛ وتبقى هذه الوحدات خارج النطاق وغير معدّة للتشغيل ضمن هذا الإغلاق.

| المجال | التنفيذ المنجز |
|---|---|
| Product Master | إنشاء منتج محكوم متعدد اللغات ووحدات قياس وأسعار، مع إدخال باركود نصي والتحقق من صيغته. |
| الدفعات وFEFO | إنشاء وعرض الدفعات، تغيير حالتها، تسوية كميتها بسجل تدقيق، ومنع صرف المنتهي. |
| المبيعات | إنشاء فاتورة مسودة، إصدار ذري وفق FEFO، إنشاء حركات صرف، وتسجيل السداد. |
| المشتريات | إنشاء أمر شراء وإرساله واستلامه، مع إنشاء الدفعات وحركات الاستلام. |
| التحويلات | إنشاء، اعتماد، إرسال، واستلام تحويل بين مخزنين مع حركات خروج ودخول موثقة. |
| الجرد | إنشاء الجرد وبدؤه وإرساله للمراجعة واعتماده مع تسويات فروقات المخزون. |
| التقارير والواجهة | مؤشرات التجارة وأحدث الفواتير والأوامر والتنبيهات المرئية في Workspace، وربط مسار التجارة بـ Nawa Flow. |

## حواجز الحوكمة والعزل

تتحقق الإجراءات من العضوية، وتفعيل الوحدة، وسياق المؤسسة قبل استدعاء طبقة البيانات. كما تتحقق عمليات الفاتورة والشراء والتحويل والجرد من ملكية المنتجات والمخازن والدفعات والمستندات للمؤسسة نفسها. يُسجل إصدار الفواتير، واستلام الطلبات، وتسويات الدفعات، والتحويلات، واعتماد الجرد في سجل التدقيق.

## نتائج التحقق

| الفحص | النتيجة |
|---|---|
| فحص TypeScript (`pnpm check`) | ناجح. |
| اختبارات Vitest (`pnpm test`) | ناجح: **17 ملف اختبار و32 اختباراً**. |
| اختبارات قاعدة البيانات | تغطي رفض FEFO للدفعات المنتهية، وتحويل الدفعات، وتسوية الجرد، وعزل التحويل والجرد وFEFO بين مؤسسات مختلفة. |
| المراجعة المرئية | صفحة التجارة تعرض حالة الإعداد عند غياب عضوية المؤسسة؛ يلزم حساب ذو عضوية ومؤسسة لرؤية النماذج التشغيلية والبيانات الحقيقية. |
| البناء الإنتاجي (`pnpm build`) | لم يكتمل: توقّف في محاولات الإنتاج والتشخيص (`--minify=false`) بخروج `143` أو `SIGTERM` أثناء `rendering chunks` بعد تحويل 6468 وحدة. يجب معالجة حد زمن أو موارد البناء في البيئة قبل النشر. |

> لا تُعد نتيجة البناء المكتمل ناجحة في هذه المرحلة. لا يُوصى بالنشر قبل معالجة هذا القيد وإعادة التحقق من البناء الإنتاجي.

## الأعمال التالية خارج الإغلاق الحالي

تبقى مراجعات المنصة الأوسع في `todo.md`، ومنها توحيد النصوص القديمة في جميع الشاشات، الطباعة المتعددة اللغات، ومراجعة البناء الإنتاجي. كما ينبغي إضافة واجهات مخصصة للتحويل والجرد ضمن مساحة التجارة عند الانتقال من نواة العمليات إلى تجربة التشغيل الموسعة.

## تحسينات لاحقة في المرحلة

أضيفت اختبارات قاعدة بيانات لعزل سجل أسعار الصرف ومرشحات التاريخ والعملة، واختبارات قابلة للتشغيل لتصدير Excel وPDF متعدد الصفحات. كما نُقلت النصوص الأساسية للوحة أسعار الصرف إلى القاموس المركزي وربط حارس دور مالك المؤسسة باختبار مباشر.
