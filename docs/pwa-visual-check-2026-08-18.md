# تحقق مرئي لـPWA وتكامل المسح

تمت معاينة `/commerce/products` و`/commerce#operations` على هاتف بعرض 390px بعد تسجيل طبقة PWA. ظهر شريط **«تثبيت التطبيق»** بوضوح في أسفل الواجهة عند دعم المتصفح لإشارة التثبيت، من دون حجب حقل البحث أو إدخال المنتج. ظل جدول المنتجات قابلاً للتمرير أفقياً داخل سطحه فقط، وبقي نموذج إدخال المنتج متجاوباً مع حقل الباركود وزر الكاميرا وزر كتم الصوت وتلميح قارئ USB.

لا تطلب طبقة PWA إذن كاميرا أو طباعة؛ يظل كل منهما معتمداً على تفاعل المستخدم الصريح ضمن الماسح وحوار الملصقات. لا يمكن للمحاكاة المرئية منح إذن كاميرا مادية أو تنفيذ نافذة طباعة فعلية، ولذلك يظل التحقق النهائي لهذين الإذنين مطلوباً على جهاز المستخدم عند الإطلاق.
