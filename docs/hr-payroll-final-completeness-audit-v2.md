# مصفوفة تدقيق الإكمال النهائي للموارد البشرية والرواتب

## نقطة الأساس

نقطة الأساس المثبتة هي `50c6e60`، أحدث نقطة استقرار قبل التعديلات الجارية على وثائق المركبات. تعتمد المصفوفة على الخدمات والمخططات والاختبارات والواجهات الفعلية، ولا تعيد بناء بوابة الموظف أو تصدير البنك أو المحرك المالي الموجود.

| المجال | الحالة | الدليل التشغيلي أو الفجوة |
|---|---|---|
| Employee Master، Employee/User، الأقسام، المناصب، المدير | DONE | ملف مستقل وربط مستخدم اختياري وكيانات تنظيم ومدير مباشر خادمي. |
| العقود وجداول العمل | DONE | نوع العقد والتواريخ وأساس ومبلغ الراتب والعملة والجدول والحالة. |
| الحضور، الغياب، ساعات العمل الإضافية | PARTIAL | الحضور والساعات الإضافية والاعتماد متوفرة؛ الغياب لا يولّد خصماً قابلاً للتهيئة من الحضور الفعلي. |
| الإجازات والأرصدة | DONE | تقديم واعتماد المدير ورفض وإلغاء ورصيد قابل للتهيئة ومنع التجاوز وتدقيق. |
| فترات الرواتب والتشغيل والحساب وإعادة الفتح | DONE | حالات Draft/Calculated/Approved/Posted/Paid، لقطة واعتماد وإعادة فتح بسبب، مع منع إعادة فتح المدفوع. |
| الراتب الأساسي والبدلات والخصومات والمكافآت والإجمالي والصافي | PARTIAL | الحساب الحتمي موجود، لكن خصم الغياب القابل للتهيئة غير مرتبط بالحضور. |
| السلف والاسترداد | DONE | Submitted/Approved/Rejected/Paid/Recovered، واسترداد على فترة واحدة أو متعددة مع حد الرصيد. |
| العمولات | PARTIAL | قواعد وقيود مصدر فريد موجودة؛ الربط التلقائي المضبوط بأحداث البيع أو التحصيل الصالحة ما زال ناقصاً. |
| Snapshot وإعادة الحساب قبل الاعتماد | DONE | تحديث الحساب قبل الاعتماد فقط، وتثبيت لقطة وقسيمة عند الاعتماد. |
| الترحيل والدفع والمالية ومنع التكرار | DONE | مطابقات حسابات بلا معرّفات ثابتة، وفصل اعتماد/ترحيل/دفع ومصادر فريدة. |
| القسيمة | PARTIAL | لقطة وقسيمة خاصة للموظف موجودتان؛ PDF/Print مستقل متعدد اللغات للقسيمة غير مكتمل. |
| تصدير بنك الرواتب | DONE | CSV لفترة مدفوعة فقط، وتحقق حساب وصافي وصلاحية منفصلة. |
| الخدمة الذاتية للموظف والمدير | DONE | ملف وحضور وقسائم وإجازات وسلف شخصية، ومدير مباشر يقرر طلبات فريقه فقط. |
| التقارير وExcel/PDF/Print | PARTIAL | سجل رواتب محمي وتصدير Excel ودليل موظفين Print؛ تقارير HR مفلترة وقسائم PDF منفصلة ناقصة. |
| الصلاحيات والنطاق والسرية | PARTIAL | صلاحيات HR مفصلة وسرية راتب خادمية؛ نطاق الفرع والقسم غير موحد في كل عقد HR. |
| التدقيق وi18n وRTL/LTR | DONE | تدقيق انتقالات أساسية وواجهات عربية/فرنسية/إنجليزية واتجاهان. |

## نطاق الإصلاح

ستركز الدفعة على خصم الغياب القابل للتهيئة، وتقييد مصدر العمولات، وقسيمة قابلة للطباعة أو PDF، وتحسين تقارير HR العملية وحراسة النطاق حيث توجد فجوة مؤكدة. لا يشمل ذلك محرك قوانين خاصاً بدولة أو جهاز بصمة أو توظيف أو AI.
