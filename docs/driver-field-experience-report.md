# تقرير تجربة السائق الميداني

## الملخص التنفيذي

اكتملت واجهة السائق الميداني في Nawa ERP كمسار مستقل ومهيأ للهاتف ضمن `/driver`. لا تعرض الواجهة سوى الجولات والمحطات المسندة صراحةً إلى العضوية الحالية عبر نطاق `assignedRouteIds`. وتدعم الواجهة متابعة المحطات، فتح الملاحة، تسجيل الوصول الجغرافي، مشاركة الموقع الاختيارية، وإثبات التسليم بالصورة والتوقيع الإلكتروني.

| مؤشر الجودة | النتيجة |
|---|---:|
| نقطة الاستعادة | `3c4ebbdb` |
| الترحيل المطبق | `0011_colossal_shriek.sql` |
| ملفات الاختبار الناجحة | 43 |
| الاختبارات الناجحة | 94 |
| فحص TypeScript | ناجح |
| التحقق المرئي | واجهة السائق متجاوبة على الهاتف |

## الوظائف المنفذة

تقرأ واجهة السائق الجولات النشطة المصرح بها فقط، وتعرض المحطات وبيانات العميل وإحداثياته والأولوية التشغيلية. يستطيع السائق بدء تنفيذ الجولة أو بدء العودة وفق انتقالات الحالة المحكومة، كما يستطيع تأكيد الوصول عند توافر موقع الجهاز وإحداثيات المحطة؛ ويُحفظ الحدث في سجل Geofence المرتبط بالمؤسسة والجولة.

| المجال | التنفيذ | ضابط الحماية |
|---|---|---|
| الوصول | `driver.myRoutes` يعيد الجولات ضمن المسارات المسندة للعضوية فقط | تحقق الصلاحية والوحدة ونطاق `assignedRouteIds` |
| الموقع | تشغيل GPS لا يبدأ إلا بعد موافقة صريحة ويمكن إيقافه فوراً | لا يوجد تتبع خلفي أو إرسال موقع قبل الموافقة |
| العمل دون اتصال | طابور `localStorage` محدود إلى 200 نقطة لكل جولة مع مزامنة عند عودة الاتصال أو يدوياً | لا يخزن إلا نقاط الجولة الحالية ويزيل النقاط بعد نجاح الإرسال |
| إثبات التسليم | صورة حتى 5 ميغابايت وتوقيع مرسوم واسم مستلم | مراجع الملفات في S3، لا bytes داخل قاعدة البيانات، وتحقيق محطة/عميل/جولة مؤسسي |
| الفرز | أولوية العميل أو المسافة المتبقية من موقع السائق أو التسلسل | لا يغير ترتيب الجولات أو المحطات في البيانات الأصلية |

## إثبات التسليم والتخزين

أضيف جدول `distribution_delivery_proofs` ضمن الترحيل `0011_colossal_shriek.sql`. يحتوي الجدول مراجع التخزين للصورة والتوقيع واسم المستلم وتوقيت التوقيع، ويرتبط بالمؤسسة والجولة والمحطة والعميل، مع قيد فريد يمنع إثباتين للمحطة نفسها داخل المؤسسة. تتحقق الخدمة الخادمية من انتماء المحطة والجولة والعميل والتسليم الاختياري إلى المؤسسة قبل التخزين، وتكتب سجل تدقيق عند نجاح العملية.

> الصورة والتوقيع لا يُحفَظان داخل قاعدة البيانات. تحفظ قاعدة البيانات المفتاح والرابط فقط، فيما تحفظ البايتات في التخزين الكائني الآمن.

## التحقق

تغطي الحزمة الاختبارية طابور مواقع السائق المحلي والحفظ والإزالة الانتقائية بعد المزامنة، كما تغطي واجهة السائق عرض الجولة المسندة وموافقة الموقع وإجراء بدء التنفيذ وظهور إثبات التسليم عند الوصول. اجتاز المشروع فحص TypeScript و43 ملف اختبار تضم 94 اختباراً ناجحاً.

## الحدود المقصودة والخطوة التالية

يوفر التنفيذ طابوراً محلياً للموقع، لكنه ليس تطبيقاً أصلياً يعمل كخدمة خلفية دائمة عند إغلاق المتصفح. الخطوة المناسبة لاحقاً هي تطبيق سائق أصلي أو PWA مع Service Worker وخلفية نظام تشغيل، مع إدارة مفاتيح جلسة لتشفير الطابور المحلي وإتاحة توقيع متعدد الأطراف عند الحاجة.
