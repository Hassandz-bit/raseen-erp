# تقرير مرحلة الموارد البشرية والرواتب

## الحالة التنفيذية

**الحالة: PARTIAL — نواة HR والرواتب والتكامل المالي مكتملة وقابلة للتشغيل، بينما تظل بعض توسعات enterprise المتقدمة خارج هذه الدفعة وفق الحدود المقررة.**

نقطة الأساس هي `5a03e643`. شملت الدفعة ترحيلات `0026_ordinary_miek.sql` و`0027_stormy_prowler.sql`، مع إضافة جداول مستقلة ومتوافقة مع أساس الموظف والحضور السابق.

| المجال | التنفيذ |
|---|---|
| الموظف والتنظيم | ملف موظف موسع وربط اختياري بمستخدم التطبيق، وأقسام ومناصب وجداول عمل وعقود عمل وفصل صريح بين Employee وUser. |
| الحضور والإجازات | حضور يدوي/مشرف مع ساعات وتأخير وانصراف مبكر، أنواع وأرصدة وطلبات إجازة بحالات مسودة/مقدمة/معتمدة/مرفوضة/ملغاة، وساعات إضافية تعتمد قبل إدراجها. |
| الرواتب | فترات رواتب، حساب حتمي من العقد والبدلات والساعات الإضافية والعمولات والضبط والسلف، لقطة JSON غير قابلة للتعديل بعد الاعتماد، وقسائم راتب محفوظة. |
| السلف والعمولات | سلف بمعرف منع تكرار وطريقة استرداد، وقواعد وقيود عمولات مرتبطة بمصدر تشغيل فريد لمنع احتساب المصدر ذاته مرتين. |
| المالية | ترحيل رواتب معتمدة ودفعها وترحيل السلفة عبر المطابقات `payroll_posting` و`payroll_payment` و`employee_advance_*`؛ لا توجد معرفات حساب ثابتة في قواعد HR. |
| السرية | بطاقات HR العامة لا تعرض مبالغ الرواتب؛ ملخص الرواتب وعمليات الاعتماد والترحيل تتطلب مالك وحدة HR خادمياً. |
| الواجهة | مسار `/hr` عربي/فرنسي/إنجليزي مع RTL/LTR، دليل موظفين، حضور وإجازات وساعات إضافية، تبويب رواتب محمي، تصدير Excel وطباعة PDF لدليل الموظفين، ورابط في Nawa Flow والشريط الجانبي. |

## اختبارات الجودة

| التحقق | النتيجة |
|---|---|
| `pnpm check` | ناجح. |
| `pnpm lint` | ناجح بلا أخطاء؛ تبقى تحذيرات موروثة غير مرتبطة بالمرحلة في ملفات سابقة. |
| `pnpm test` | ناجح: **62 ملف اختبار و128 اختباراً**. |
| دورة الرواتب | اختبار قاعدة بيانات يغطي البدلات والخصم والسلفة والحساب واللقطة والاعتماد والترحيل والدفع ومنع الترحيل الثاني. |
| أساس HR | اختبار قاعدة بيانات يغطي فصل Employee/User والعزل والحضور والإجازة والساعات الإضافية. |
| الواجهة | اختبار مركز HR ومراجعة مرئية بالعربية والفرنسية والإنجليزية، مع عدم ظهور راتب في اللوحات العامة. |
| `pnpm build` | ناجح؛ تحذير غير مانع لحجم حزمة واجهة أكبر من 500KB. |

## عناصر PARTIAL أو مؤجلة عمداً

لا يتضمن هذا الإغلاق محرك قوانين عمل أو ضرائب خاصاً بدولة، أو جهاز بصمة، أو إقرارات حكومية، أو ATS أو إدارة أداء متقدمة. كما أن صلاحيات HR المفصلة حسب الفرع والمدير المباشر وEmployee Self-Service جاهزة على مستوى نموذج البيانات والربط الاختياري، لكنها تحتاج طبقة أدوار مخصصة مستقلة قبل تفعيلها. لا توجد أيضاً واجهة إنشاء وتعديل كاملة لكل نموذج HR أو مولد PDF منفصل لقسيمة راتب؛ التصدير الحالي يستخدم أساس Excel والطباعة المتاحين.
