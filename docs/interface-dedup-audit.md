# تدقيق تكرار الواجهات والمداخل

## النتيجة التنفيذية

يوجد **تكرار وظيفي حقيقي واحد**: نافذة «مساعد نواة» العائمة داخل الصفحة الرئيسية. هذه النافذة محاكاة محلية تعرض رسالة ثابتة ولا تستخدم عقد الذكاء الاصطناعي الخادمي، بينما صفحة `/workspace` هي واجهة Nawa AI الفعلية المحكومة بالسياق والاشتراك والصلاحيات. ستُزال النافذة العائمة ويصبح زرها اختصاراً صريحاً إلى Nawa AI.

لا يعد **Nawa Flow** تكراراً لـNawa AI. Nawa AI يفسر بيانات المؤسسة المصرح بها ويقترح توصيات غير تنفيذية؛ Nawa Flow خريطة مرئية للوحدات والمسارات وحالات الاشتراك. ومع ذلك، مدخل Flow المنفصل في الشريط الجانبي يسبب التباساً بصرياً، لذا سينقل الوصول إليه إلى داخل مساحة Nawa AI كعرض ثانوي بدلاً من اعتباره أداة مستقلة على المستوى الأول.

| الواجهة أو المدخل | القرار | المبرر |
|---|---|---|
| نافذة مساعد الصفحة الرئيسية | حذف | محاكاة مكررة لا تستدعي الحارس أو عقد AI الفعلي. |
| Nawa AI في `/workspace` | احتفاظ | واجهة تحليل محكومة بالمؤسسة والوحدة والصلاحيات. |
| Nawa Flow | احتفاظ مع دمج مدخل | خريطة تدفق ووحدات وليست مساعداً ذكياً؛ سيصبح تبويباً داخل مساحة AI. |
| Home ModuleView | احتفاظ | معاينة سريعة للوحة الرئيسية، بينما صفحات التجارة والتوزيع والمالية تشغيلية مستقلة. |
| DashboardLayout وHome sidebar | توحيد التنقل | غلافان لأجزاء مختلفة من التطبيق؛ ستتطابق المداخل العليا وترتيبها دون دمج معماري قسري. |

## نطاق الحذف الآمن

لن تحذف أي عقود خادمية أو جداول أو مكونات `AIChatBox` أو `NawaFlow`. التغيير مقتصر على إزالة طبقة العرض الوهمية، وتوجيه المستخدم للمسار المحكوم، وإزالة المدخل الأعلى الزائد لـNawa Flow بعد توفير انتقال واضح من مساحة Nawa AI.

## نتيجة التنفيذ والتحقق

أزيلت نافذة المحادثة المحلية العائمة، وبطاقة الترويج الجانبية المتصلة بها، واختصارها العائم. يشير زر الرأس الآن إلى **Nawa AI** ويقود إلى `/workspace`، وهو المسار الذي يستخدم عقد AI الخادمي. أزيل مدخل Nawa Flow من التنقل الأعلى في مساحة العمل، وأصبح وصلة «Nawa Flow · العمليات» داخل رأس Nawa AI.

| التحقق | النتيجة |
|---|---|
| TypeScript | PASS |
| اختبارات التنقل | PASS — 3 ملفات و7 اختبارات |
| Lint | PASS بلا أخطاء؛ 12 تحذيراً موروثاً لم تتغير |
| مراجعة بصرية | PASS — اختفى المساعد المحلي من الصفحة الرئيسية، وظهر Flow داخل Nawa AI. |
