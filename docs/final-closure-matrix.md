# مصفوفة التدقيق النهائي — Nawa ERP

| المجال | الحالة | دليل التنفيذ | المتبقي أو القيد |
|---|---|---|---|
| عزل المؤسسات | DONE | حراس المؤسسة واختبارات عزل قاعدة البيانات للمخزون والمستندات | لا يوجد ضمن النطاق الحالي |
| التجارة والمخزون | DONE | منتجات ودفعات وFEFO ومستندات وتحويلات وجرد وسجل تدقيق | خارج النطاق: توزيع وتصنيع وأساطيل |
| الأسعار والعملات | DONE أساسياً | كتالوج عملات، عملة أساس مقيدة، سجل صرف مفلتر وتصدير Excel/PDF | مراجعة متصفح مسجل الدخول لتحميل لوحة الأسعار |
| التفضيلات | DONE أساسياً | مظهر وخط وحجم ونمط أرقام وإعادة ضبط، مع اختبار وحدات | اختبار تفاعل المتصفح للمزود ما زال مفيداً |
| الطباعة | PARTIAL | قالب متعدد المقاسات، معاينة عربية آمنة، وتنزيل HTML صريح مع طباعة أو حفظ PDF عبر المتصفح واختبار مكوّن للإجراءات | تنزيل PDF مباشر وخطوط مستند معتمدة واختبار تفاعل متصفح كامل |
| التدويل | PARTIAL | قاموس عربي/فرنسي/إنجليزي، اختبارات تكافؤ، وتصدير ملخص مترجم، واختبارات واجهة للبطاقات المالية وInsightsPanel، وإجراءات تشغيلية مترجمة، وتوطين الفواتير والتنبيهات وصحة المخزون في لوحة التحكم | نصوص تشغيلية موروثة وتعميمات إضافية على لوحات الواجهة العامة |
| مركز الإعدادات | PARTIAL | اللغة، المظهر، العملات، أسعار الصرف، التواريخ والطباعة، وقسم فروع معزول بحراسة المالك ورسائل أخطاء مترجمة واختبارات نجاح/تعارض | المستخدمون والأمان والاشتراك بحاجة واجهات تشغيلية مكتملة |
| مراجعة الاتجاهات | DONE أساسياً | مراجعة RTL وLTR بالفرنسية للهاتف واللوحي وسطح المكتب؛ دون تراكب ظاهر في الأجزاء المرئية | مراجعات تفاعلية أوسع عند إضافة واجهات تشغيلية جديدة |
| الجودة | PARTIAL | `check` ناجح، 30 ملف اختبار و60 اختباراً ناجحاً، مع بيئة DOM لاختبارات المكوّنات وحراسة مالك المؤسسة | البناء يتوقف عند rendering chunks تحت حد موارد البيئة؛ 3 تحذيرات إطار غير حاجبة موثقة |

> تعتمد هذه المصفوفة على الحالة الفعلية لا على افتراض اكتمال جميع الأقسام. البنود PARTIAL تبقى ظاهرة في `todo.md` ولا تمثل إغلاقاً وظيفياً كاملاً.
