# مصفوفة التدقيق النهائي — Nawa ERP

| المجال | الحالة | دليل التنفيذ | المتبقي أو القيد |
|---|---|---|---|
| عزل المؤسسات | DONE | حراس المؤسسة واختبارات عزل قاعدة البيانات للمخزون والمستندات | لا يوجد ضمن النطاق الحالي |
| التجارة والمخزون | DONE | منتجات ودفعات وFEFO ومستندات وتحويلات وجرد وسجل تدقيق | خارج النطاق: توزيع وتصنيع وأساطيل |
| الأسعار والعملات | DONE | كتالوج عملات، عملة أساس مقيدة، سجل صرف تاريخي مفلتر وتصدير Excel/PDF منسق وفق المؤسسة، واختبارات للتحميل والخطأ والتصفية والتصدير | مراجعة تشغيلية فقط عند إضافة عملات أو تقارير جديدة |
| التفضيلات والتنسيق | DONE | تفضيلات لغة ومظهر وخط وأرقام وتاريخ ووقت ومنطقة زمنية، ومنسقات مركزية مطبقة على القيم الإنتاجية والتصديرات النشطة | المكونات العامة وملفات الاختبار فقط تحتفظ بصيغ معيارية مقصودة؛ انظر `formatting-coverage-audit.md` |
| الطباعة | DONE | قالب متعدد المقاسات، خط وحجم مستقلان للمستند، معاينة عربية آمنة، وتنزيل HTML وPDF مباشر واختبارات للأبعاد وBlob والإجراءات | مراجعة تشغيلية عند إضافة قالب مستند جديد |
| التدويل | DONE | قاموس عربي/فرنسي/إنجليزي، اختبارات تكافؤ، بيانات تجريبية محايدة، واختبارات واجهة تمنع النص العربي الثابت في LTR ضمن ModuleView ولوحة التحكم | مراجعة تشغيلية دورية عند إضافة واجهات جديدة |
| مركز الإعدادات | DONE | المؤسسة واللغة والمظهر والخطوط والعملات والصرف والتواريخ والطباعة والفروع والمستخدمون والإشعارات والأمان والاشتراكات، مع حالات تحميل وفراغ وخطأ واختبارات واجهة | قسم الاشتراكات يقرأ مخرج `bootstrap` المحمي ولا يكشف بيانات خارج المؤسسة |
| مراجعة الاتجاهات | DONE | مراجعة RTL وLTR بالفرنسية للهاتف واللوحي وسطح المكتب، ومراجعة إعدادات RTL على الهاتف؛ دون تراكب ظاهر في الأجزاء المرئية | مراجعات تفاعلية أوسع عند إضافة واجهات تشغيلية جديدة |
| الجودة | DONE مع قيد بيئي موثق | `check` ناجح و36 ملف اختبار و84 اختباراً ناجحاً، مع اختبارات DOM للمكوّنات وحراسة المالك والوحدة | البناء الإنتاجي ما زال يتوقف عند rendering chunks بسبب حد موارد البيئة، مع 3 تحذيرات إطار غير حاجبة موثقة؛ ليس فشلاً في TypeScript أو الاختبارات |

> نقطة الاستعادة المبدئية المرتبطة بهذه المصفوفة: `6081d655`. ستُحدّث إلى نقطة الإغلاق النهائية بعد تضمين تصحيح حالة الاشتراكات والوثائق النهائية. تعتمد المصفوفة على الحالة الفعلية لا على افتراض اكتمال جميع الأقسام، وتفصل بين قيد بيئة البناء والتحقق البرمجي الناجح.
