# إغلاق تصدير PDF الرسمي لفواتير المبيعات

يتيح مسار تفاصيل فاتورة المبيعات الآن زر **«تنزيل PDF رسمي»**. ينشئ الزر ملف PDF من بيانات الفاتورة التي يقرأها الخادم ضمن المؤسسة الحالية، وليس من قيم مبلغ أو ضريبة يحسبها المتصفح.

يتضمن الملف اسم المؤسسة، رقم الفاتورة، العميل والحالة والتواريخ، وطريقة عرض السعر، وتفاصيل كل بند مع الكمية والوحدة وسعر الوحدة والنسبة الضريبية والإجمالي. وينتهي بملخص رسمي لصافي المبلغ وضريبة القيمة المضافة والخصم عند وجوده والإجمالي المستحق. كما يحترم إعدادات المستند للمؤسسة: مقاس الورق والخط والحجم والتذييل وخيار التوقيع.
