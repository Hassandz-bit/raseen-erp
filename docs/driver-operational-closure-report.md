# تقرير إغلاق دورة السائق التشغيلية

## الملخص التنفيذي

اكتملت توسعة تطبيق السائق من واجهة متابعة مسار إلى واجهة تشغيل يومي ضمن عقود التوزيع الحالية. يقتصر الوصول على الجولات المسندة للعضوية، وتبقى المركبة مخزناً متنقلاً فعلياً. تدعم الواجهة التسليم الكامل أو الجزئي أو المتعذر، والتحصيل، والمرتجع، والمصروف، وبيع المركبة، وإقفال الجولة، مع إثبات تسليم سابق بالصورة والتوقيع وبموافقة صريحة لمشاركة GPS.

| محور التنفيذ | النتيجة |
|---|---|
| المخزون | قراءة مخزون المركبة مقيدة بالجولة المسندة، مع منتج ودفعة وصلاحية وكمية متبقية |
| التسليم | تسليم كامل أو جزئي أو متعذر، وإثبات صورة وتوقيع للمحطة المسندة |
| المالية | تحصيل ومرتجع ومصروف وإرسال إقفال الجولة عبر مسارات التوزيع المحكومة |
| بيع المركبة | فاتورة مبيعات من المخزن المتنقل وإصدار FEFO مع مفتاح idempotency، دون نظام مبيعات موازٍ |
| المحطات | تخطٍ أو فشل بسبب إلزامي وسجل تدقيق؛ لا تعديل صامت لمحطة منجزة |
| دون اتصال | طابور مواقع قائم وطابور عمليات محلي محدود بـ100 عملية لكل جولة، مع حالات pending وneeds_refresh وsupervisor_review |
| PWA والخصوصية | manifest لتثبيت محدود؛ لا ادعاء تتبع خلفي بعد إغلاق التطبيق |

## ضوابط الوصول والسلامة

يتحقق كل مسار ميداني من وحدة التوزيع، وصلاحية المستخدم، ونطاق `assignedRouteIds`، والمؤسسة. لا يمكن للسائق قراءة مخزون مركبة خارج الجولة المسندة أو تسجيل إثبات أو بيع أو انتقال محطة خارجها. يتحقق بيع المركبة من المخزون الصالح داخل مخزن المركبة، وينشئ فاتورة من المسار التجاري القائم ثم يصدرها بخوارزمية FEFO؛ ولا تقبل الواجهة عملة ثابتة لبيع المركبة، إذ يرث الخادم عملة الأساس من المؤسسة.

> لا يحفظ التطبيق أسرار جلسة أو ملفات كبيرة في الطوابير المحلية. الصور والتوقيعات تحفظ كمراجع S3 محكومة، وتظل مواقع GPS رهناً بموافقة واضحة من السائق.
