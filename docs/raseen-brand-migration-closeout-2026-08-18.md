# إغلاق هجرة العلامة إلى RASEEN

نُفذت هجرة العلامة الظاهرة من **Nawa ERP** إلى **RASEEN ERP / رصين**، مع اعتماد **بوابة التاجر** كتسمية عربية ظاهرة لقسم Nawa Retail. بقيت المعرفات والمسارات والعقود التقنية باسمها السابق عندما تكون جزءاً من التوافق التشغيلي أو عزل البيانات.

| السياق الظاهر | الاسم المعتمد |
|---|---|
| المنصة | RASEEN ERP / رصين لإدارة الأعمال |
| الذكاء | RASEEN AI / ذكاء رصين |
| التدفقات | RASEEN Flow / تدفق رصين |
| Retail بالعربية | بوابة التاجر |
| Retail بالإنجليزية | RASEEN Merchant Portal |
| Android | اسم التطبيق RASEEN ERP؛ يبقى `com.nawa.erp` ثابتاً للتوافق |

تم تحديث الرأس وصفحة البوابات وRail ومساحة الذكاء وبوابة التاجر وصفحات المالية والموارد البشرية وملفات PWA وصفحات عدم الاتصال والتقارير والفواتير. كما جرى إعادة مزامنة Android وبناء `RASEEN-ERP-debug.apk` و`RASEEN-ERP-debug.aab` مع تحقق اسم التطبيق الظاهر `RASEEN ERP` واسم الحزمة `com.nawa.erp`.

## ما بقي ثابتاً عمداً

تبقى أسماء الملفات والمكونات ودوال API ومسارات URLs ومفاتيح التخزين وسجل البيانات القديمة، مثل `nawa-erp-sw.js` و`nawa_flow` و`com.nawa.erp`، لضمان عدم كسر التثبيت الحالي أو روابط المستخدمين أو العقود الخادمية. كما لم يتغير اسم شركة Demo أو بيانات المؤسسات، لأنها بيانات أعمال معزولة وليست علامة واجهة.

## التحقق

نجح `pnpm check` و`pnpm lint` و**242 اختباراً في 106 ملفات**. تمت معاينة صفحة البوابات ومساحة RASEEN AI وبوابة التاجر وطلبات التاجر بعد إعادة التشغيل، وتأكدت إزالة تسمية Retail من العناوين الظاهرة للعمليات. كما أعيد بناء APK وAAB التجريبيين باسم RASEEN ERP للتحقق الداخلي.
