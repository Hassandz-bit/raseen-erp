# تقرير إغلاق التشغيل — التصنيع والإنتاج

**المشروع:** Nawa ERP  
**نقطة البداية:** `2f08a32b`  
**نقطة الاستقرار البرمجية:** `4ad65596`  
**النطاق:** إغلاق الفجوات التشغيلية في التصنيع فقط، دون البدء في المالية الكاملة أو MRP متقدم أو الذكاء الاصطناعي أو إعادة بناء نواة التصنيع.

## الملخص التنفيذي

أصبحت وحدة التصنيع قابلة للتشغيل من الواجهة وفق صلاحيات تشغيلية دقيقة، بدلاً من تقييد التشغيل بمالك المؤسسة وحده. تُفرض الصلاحيات ونطاقات البيانات على الخادم، وتشمل المؤسسة والفرع وخط الإنتاج ومخزن المواد الخام ومخزن المنتج النهائي. كما أضيفت مساحة تشغيل فعلية لأمر الإنتاج، ووثائق تشغيل قابلة للطباعة والتنزيل، وملصق دفعة حراري، وشجرة نسب للدفعات في الاتجاهين.

| المحور | نتيجة الإغلاق |
|---|---|
| نموذج الصلاحيات | صلاحيات تصنيع دقيقة مع أدوار اختيارية قابلة لإعادة الاستخدام |
| نطاق البيانات | فرع وخط إنتاج ومخازن خام/نهائي، مع فلترة الخادم للقراءات والخيارات |
| تشغيل أمر الإنتاج | إنشاء، تخطيط، اعتماد، حجز، سحب، مراحل، مخرجات، جودة، هدر، تكلفة، إقفال |
| الوثائق | عشرة أنواع من وثائق التشغيل مع HTML وPDF والطباعة |
| التتبّع | Batch Genealogy للخام إلى النهائي والعكس |
| التحقق | `lint` بلا أخطاء، و`check` ناجح، و53 ملف اختبار مع 114 اختباراً ناجحاً |

## 1. نموذج الصلاحيات والأدوار

نُفّذت صلاحيات تغطي العرض، وإدارة BOM، ودورة أمر الإنتاج، وحجز المواد وسحبها وإرجاعها، وتسجيل الاستهلاك والمخرجات والهدر وإعادة التشغيل، والجودة وإطلاق الدفعات، والتكاليف والتقارير. يحتفظ دور المالك بكل الصلاحيات، بينما تتيح الإعدادات أدواراً تشغيلية اختيارية لا تفرض على كل مؤسسة.

| الدور الاختياري | نطاق القدرات |
|---|---|
| مدير الإنتاج | التخطيط والاعتماد وإدارة دورة الإنتاج الكاملة والتكلفة والتقارير |
| مشرف الإنتاج | بدء الإنتاج ومتابعة المراحل وتسجيل المخرجات والهدر ضمن نطاقه |
| عامل المخزن | الحجز والسحب والإرجاع ضمن مخازنه المسموح بها |
| مفتش الجودة | الفحص والاعتماد وإطلاق الدفعة من الحجر، من دون صلاحية تكلفة افتراضية |
| مراقب التكلفة | عرض وتعديل تكاليف الإنتاج والتقارير دون منح صلاحيات تشغيل المخزن |
| المالك | جميع الصلاحيات ضمن المؤسسة |

يُرفض أي عقد خادمي لا يطابق الصلاحية المطلوبة أو يقع خارج نطاق عضوية المستخدم. وتشمل القراءة نفسها: قائمة الأوامر وملخص المركز وخيارات خطوط الإنتاج والمخازن تتقلص وفق النطاق قبل وصولها للواجهة.

## 2. واجهة تشغيل أمر الإنتاج

أضيف زر **أمر إنتاج جديد** إلى مركز التصنيع. يختار المستخدم BOM النشط والكمية والمخزنين وخط الإنتاج، ثم يواصل دورة العمل داخل مساحة تشغيل منظمة. تعرض مساحة الأمر المحاور التالية: نظرة عامة، المواد، المراحل، الاستهلاك، المخرجات، الهدر والتالف، الجودة، التكاليف، التتبّع، وسجل التدقيق.

| التدفق | التنفيذ من الواجهة |
|---|---|
| التخطيط والاعتماد | انتقالات حالة خاضعة للصلاحية ومؤرشفة في التدقيق |
| المواد | Required وAvailable وReserved وIssued وReturned والانحراف، مع تمييز النقص ودفعات FEFO |
| المراحل | حالات جاهز/قيد التنفيذ/مكتمل/معطل/متخطى، وتسجيل البداية والنهاية خادمياً |
| الإنتاج | تسجيل المخرج وإنشاء Finished Batch وربطها بالأمر |
| الهدر | تسجيل التالف والهدر وإعادة التشغيل بتصاريح منفصلة |
| الجودة | Pass وFail، الحجر، وإطلاق الدفعة عبر صلاحية اعتماد وإطلاق منفصلتين |
| التكلفة | مصاريف الإنتاج وبيانات التكلفة محجوبة خادمياً عمّن لا يملك صلاحية التكلفة |
| التتبّع | عرض دفعات الخام والمخرج الخاص بالأمر وسجل التدقيق |

## 3. الوثائق والملصق والتتبّع

استُخدم أساس الطباعة القائم لإضافة مستندات: أمر الإنتاج، قائمة تحضير المواد، إشعار السحب، إشعار الإرجاع، ورقة الإنتاج، استلام المنتج النهائي، ملصق الدفعة، تقرير الجودة، ورقة التكلفة، وتقرير التتبع. تعمل المستندات بالعربية والفرنسية والإنجليزية، مع اتجاه RTL/LTR، وتنزيل HTML وPDF وطباعة المتصفح.

> ملصق الدفعة يستخدم قالباً حرارياً ويعرض المنتج، رقم الدفعة، الكمية ووحدة التعبئة، تاريخ التصنيع، تاريخ الصلاحية، وحالة الجودة، مع جاهزية لرمز Barcode/QR.

تسمح واجهة **شجرة تتبع الدفعة** بإدخال معرّف دفعة داخلي، ثم عرض خام ← أمر إنتاج ← دفعة نهائية، أو العكس من الدفعة النهائية إلى دفعات الخام المستخدمة. لا تتضمن المرحلة الحالية سير استدعاء منتجات كامل، التزاماً بنطاق الإغلاق المحدد.

## 4. الاختبارات والتحقق

غطت الاختبارات سياسة الصلاحيات، مدير الإنتاج مقابل الموظف غير المصرح، مفتش الجودة من دون كشف التكلفة، نطاقات الفرع والخط والمخازن، دورة FEFO والحجز والسحب والمخرجات والحجر وإطلاق الجودة والهدر والإقفال، والتتبع النسبي للدفعات، ومركز التصنيع، ومولد وثائق التشغيل وملصق الدفعة.

| الفحص | النتيجة |
|---|---|
| `pnpm lint` | ناجح بلا أخطاء؛ 9 تحذيرات موروثة خارج ملفات مرحلة التصنيع |
| `pnpm check` | ناجح |
| `pnpm test` | ناجح: 53 ملف اختبار و114 اختباراً |
| `pnpm build` | توقف بخروج 143 عند `computing gzip size` بعد تحويل 6500 وحدة بسبب حد موارد البيئة |
| المراجعة المرئية | مركز التصنيع العربي RTL ظهر من دون تداخل أو فيض أفقي؛ حوار تشغيل أمر فعلي لم يُراجع لعدم وجود أمر في مؤسسة المعاينة |

## 5. القيود المقصودة والمعروفة

لا تتضمن هذه المرحلة جدولة السعة أو OEE أو MRP متعدد المصانع أو سير استدعاء منتجات كامل. كذلك لا يُعد توقف البناء بخروج 143 خطأً وظيفياً في TypeScript أو الاختبارات؛ فهو قيد موارد موثق في بيئة البناء الحالية. ينصح بالتحقق اليدوي النهائي من تدفقات الطباعة والتنزيل مع بيانات تشغيل فعلية قبل نشر إنتاجي.

## ملحق مراجعة المطابقة

أضافت مراجعة المطابقة اللاحقة ربط عرض إجراءي التخطيط والاعتماد بقدرات المستخدم الفعلية في الواجهة، إلى جانب الحراسة الخادمية القائمة. كما أضيف مؤشر استهلاك فعلي محسوب من الكمية المسحوبة ناقص المرتجعة في تفاصيل مواد أمر الإنتاج. اجتازت الفحوص المركزة `check` واختبار واجهة المركز واختبار تكامل التصنيع واختبار سياسة الصلاحيات بنجاح، وحُفظت نقطة الاستعادة المرحلية `1e1934b7` لهذه المراجعة.

أُضيفت أيضاً حراسة قدرة إنشاء أمر الإنتاج وتصدير تقرير التصنيع في رأس المركز، مع توسيع عقد القدرات ليشمل التقارير والاستهلاك. اجتازت الحزمة الكاملة بعد هذا التحديث **53 ملف اختبار و114 اختباراً**، كما ظل `pnpm check` ناجحاً.
