# إغلاق تجربة تثبيت Nawa ERP PWA

تطورت تجربة PWA لتقارب نمط الإرشاد المرجعي مع هوية Nawa ERP: أصبح في الرأس زر تنزيل مستقل يفتح نافذة عربية منظمة تشرح تثبيت التطبيق على الهاتف والكمبيوتر، وتعرض زر تثبيت أصلي عندما يتيحه المتصفح. لا يظهر الزر كإجراء بيع أو مزامنة، ولا يمنح صلاحية كاميرا أو طباعة أو وصول إلى بيانات المؤسسة.

| جانب التحسين | التنفيذ |
|---|---|
| أيقونات التطبيق | نسختا PNG بمقاسي 192×192 و512×512 مرفوعتان إلى تخزين المشروع ومربوطتان في Manifest، إضافة إلى `apple-touch-icon` |
| التثبيت | أيقونة تنزيل في الرأس ونافذة إرشادية عربية للهاتف والكمبيوتر، مع دعم `beforeinstallprompt` |
| التحديث | إشعار يصرح بأن إصداراً جديداً متاح ويطلب تحديث الصفحة، ثم يرسل `SKIP_WAITING` قبل إعادة التحميل عند توفر worker منتظر |
| عدم الاتصال | صفحة مستقلة آمنة لا تعرض أي بيانات مؤسسة، مع زر إعادة المحاولة وتأكيد أن API لا يخزن |
| Service Worker | يخزن shell و`offline.html` والأصول العامة فقط، ويستبعد كل `/api/` وطلبات الكتابة |

## التحقق

ظهر زر التثبيت في رأس الهاتف ضمن صفحة البوابات ومركز العمليات، وبقي إدخال الباركود وزر الكاميرا وخيار الصوت ضمن عرض 390px. تستجيب Manifest وService Worker و`offline.html` والأيقونتان برمز 200 بعد إعادة التوجيه. نجح `pnpm check` و`pnpm lint` و**238 اختباراً في 104 ملفات**، ولم تسجل سجلات المتصفح أو الطلبات أخطاء جديدة. يتطلب اختبار الإذن المادي للكاميرا ونافذة الطباعة وتثبيت النظام النهائي جهازاً حقيقياً وبناء إنتاج ناجحاً في بيئة ذاكرة أعلى.
