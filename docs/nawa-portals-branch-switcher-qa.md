# مراجعة منتقي الفروع في رأس بوابات Nawa

## النتيجة

أضيف منتقي فروع بجوار اسم المؤسسة على الشاشات الواسعة، ونسخة مماثلة داخل الشريط الجانبي عند الشاشات الأصغر. يعرض العقد الخادمي الفروع النشطة فقط ضمن المؤسسة الحالية، ويطبق نطاق `branchIds` الخاص بالعضوية عندما يكون موجوداً.

| بند | الحالة |
|---|---|
| مصدر قائمة الفروع | عقد `erp.preferences.availableBranches` محمي ويستخرج المؤسسة والنطاق من عضوية المستخدم. |
| عزل المؤسسة | لا يقبل العقد أي مدخل فرع أو مؤسسة من المتصفح. |
| الفروع غير النشطة | مستبعدة خادمياً. |
| حفظ الاختيار | يحفظ معرف الفرع المختار محلياً كمفضلة واجهة في `nawa:active-branch`. |
| سطح المكتب | PASS — يظهر المنتقي بجوار اسم المؤسسة. |
| الهاتف | PASS — يظهر المنتقي داخل الشريط الجانبي المفتوح لتجنب ازدحام الرأس. |

## حد مقصود

الاختيار الحالي يغير **سياق العرض في الرأس** ويحفظ التفضيل، لكنه لا يفرض بعد تصفية موحدة لكل استعلامات وحدات ERP؛ فهذه الاستعلامات لا تقبل سياق فرع عاماً موحداً حالياً. تبقى الحراسة الموجودة على مستوى المؤسسة ونطاق العضوية هي مصدر الأمان. فرض تصفية تشغيلية شاملة حسب الفرع يحتاج مرحلة مستقلة تمرر نطاق الفرع إلى كل عقد يدعم فروعاً، مع اختبارات انحدار مالية وتجارية ولوجستية.
