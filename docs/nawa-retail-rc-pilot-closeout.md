# تقرير إغلاق Release Candidate — Nawa ERP وNawa Retail

## قرار الجاهزية

حالة الإصدار: **PASS للطيار المحدود**. تم التحقق من العقود الخادمية والعزل والتجارة والتوزيع والمالية وتجربة Retail من خلال Fixtures معزولة قابلة للتنظيف، من دون تعديل بيانات تشغيلية دائمة أو إنشاء دورة موازية للمبيعات أو المخزون أو التوزيع.

## نتائج قبول الطيار

| مجال القبول | الحالة | دليل التحقق |
|---|---|---|
| Baseline والترحيلات | PASS | `check` و`lint` و`test` و`build` ناجحة؛ ترحيلات Retail حتى `0043` إضافية وغير هدمية. |
| بيئة الطيار | PASS | Fixture مورد وتاجران وثلاثة منافذ ومنتجات ودفعات وعروض وسياسات، مع حذف تلقائي والتحقق من عدم بقاء سجلات. |
| العلاقات والأدوار | PASS | 12 اختباراً للأدوار، الصلاحيات، نطاق المنفذ، تفويض المورد، وعزل علاقة Retail. |
| الكتالوج والتسعير والائتمان | PASS | التسعير والعروض والتوفر وحظر tampering وحساب التعرض الائتماني محكومة خادمياً. |
| الطلب والتحويل والمخزون | PASS | حارس exactly-once، سبب تعديل إلزامي، سجل تدقيق، لقطة outlet، واختبارات FEFO ومخزون التجارة. |
| التوزيع والتسليم | PASS | سعة المركبة، FEFO، حركات المركبة، العزل، وحسابات وحدات اللوجستيك ضمن الدورة القائمة. |
| المالية والعمولات | PASS | اختبارات accounting وfinance وtreasury وsales commission وtenant isolation للفواتير ناجحة. |
| الإرجاع | PASS مقيد | الطلب والمراجعة فقط؛ لا ينشأ عكس مخزون أو أثر مالي تلقائي. |
| العزل والأمان | PASS | 15 اختباراً للعزل بين المؤسسات ومالك المؤسسة والفروع والمخزون والفواتير وعلاقات Retail. |
| الهاتف وPWA والتدويل | PASS | قياس DOM على `375px` أثبت عدم وجود overflow؛ PWA لا يخزن API؛ اختبارات AR/FR/EN والتنسيق ناجحة. |
| النسخ والاستعادة | PARTIAL تشغيلياً | توثيق الإجراء موجود؛ لا يمكن تحديد تأثر الحساب أو تنفيذ تصدير/استعادة حساب فعلي من الاختبار. |

## حدود مقصودة قبل التوسع

لا تعد نتيجة الطيار دليلاً على تشغيل بيانات إنتاجية أو عمليات تاجر حية. قبل التوسع، ينبغي لصاحب الحساب التحقق من إشعار النسخ الاحتياطي داخل Manus، وإجراء Task Data Backup حديث إذا كان الحساب متأثراً، ثم تنفيذ قبول تشغيلي يدوي بحسابات مورد وتاجر حقيقية. يبقى تحسين تقسيم حزم الواجهة وتحسين batching للكتالوج فرص تحسين توسعية لا مانع إصدار للطيار.
