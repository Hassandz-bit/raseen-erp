# معمارية مرحلة الموارد البشرية والرواتب

## نقطة الأساس

نقطة الاستقرار الفعلية هي `5a03e643`، وهي تتضمن توسعة المالية والمحاسبة كاملة فوق نقطة أساس المالية السابقة `8c85c0e3`. تبقى مرحلة التصنيع عند `83ab085` مرجعاً لإغلاقها فقط. ستضاف مرحلة HR والرواتب فوق `5a03e643`، ولن تعيد بناء المالية أو التصنيع أو التجارة والمخزون أو التوزيع أو السائق أو B2B، ولن تبدأ أي ميزة AI.

## الأساسات الموجودة

يتوفر حالياً جدول موظف مبسط مع رقم واسم وقسم ومسمى وحالة، وسجل حضور مبسط، وجدول تشغيل راتب مختصر. لا توجد عقود عمل، ولا فصل اختياري بين الموظف والمستخدم، ولا سياسة رواتب أو عناصر تشغيل أو لقطات أو سلف أو إجازات أو ساعات إضافية. لذلك ستُوسّع الجداول الحالية بصورة إضافية ومتوافقة مع البيانات القائمة، وتُنقل قواعد التشغيل إلى جداول وخدمات محكومة جديدة.

## الحدود والضوابط

| المجال | القرار المعماري |
|---|---|
| الموظف والمستخدم | يبقى الموظف مستقلاً، ويضاف ربط اختياري بـ `userId` فقط. |
| التنظيم | أقسام ومناصب وجداول عمل ومراكز مسؤولية قابلة للتوسع من دون Organization Chart متقدم. |
| الرواتب | حساب حتمي من عقود وسجلات حضور وإجازات وساعات إضافية وعناصر معتمدة، مع لقطة غير قابلة للتعديل بعد الاعتماد. |
| المالية | ترحيل واعتماد ودفع عبر مطابقة الحسابات الحالية، من دون معرّفات حساب ثابتة أو قيد مكرر. |
| السرية | لا يعرض الراتب أو القسيمة أو السلفة إلا عقد خادمي محمي بصلاحيات HR/Payroll صريحة؛ المدير لا يكتسب وصول الراتب تلقائياً. |
| الامتثال | لا يوجد محرك قانوني أو ضريبي خاص بدولة؛ البدلات والخصومات والمضاعفات سياسات قابلة للإعداد. |

## النطاق المستبعد عمداً

لا يشمل التنفيذ التوظيف وATS، إدارة أداء متقدمة، أجهزة بصمة أو تكاملات حكومية، أو workforce planning متقدم. تظل قسيمة الراتب والطباعة والتصدير مبنية على أساس المستندات الحالي متعدد اللغات.
