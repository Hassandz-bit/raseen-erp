# إغلاق تخصيص ألوان RASEEN وصفحة حول التطبيق

أضيفت صفحة **ألوان رصين** في بوابة الإدارة لتسمح لكل مستخدم باختيار لون التمييز الشخصي من أربع لوحات مضبوطة: ذهب رصين، كحلي القرار، أخضر النماء، وبنفسج التخطيط. يستعمل الاختيار نظام التفضيلات الحالي ويُحفظ للمستخدم، ولا يعدل ألوان المستندات الرسمية أو بيانات المؤسسة أو ألوان مستخدم آخر.

أضيفت أيضاً صفحة **حول التطبيق** التي تعرض اسم RASEEN ERP، رقم إصدار المنصة، معرف Android التقني المستقر `com.nawa.erp`، سياسة shell الآمنة لعدم الاتصال، وطريقة تحديث PWA وتثبيت التطبيق. يفتح زر التثبيت نفس نافذة PWA الموحدة من خلال حدث مشترك مصدّر، بدلاً من إنشاء تدفق تثبيت ثانٍ.

| عنصر التحقق | النتيجة |
|---|---:|
| اختبار لوحات RASEEN ومعلومات الإصدار | ناجح |
| تحقق المهارة `saas-brand-migration` | ناجح |
| فحص TypeScript وESLint | ناجح |
| حزمة Vitest الكاملة | 244 اختباراً ناجحاً في 107 ملفات |
| معاينة سطح المكتب والهاتف | ناجحة |

تُرفق مهارة `saas-brand-migration` كحزمة مستقلة قابلة للإضافة إلى مهارات المستخدم. تغطي المهارة تدقيق ظهور العلامة، خريطة التسميات، PWA، Android، المستندات، الاختبارات، والحفاظ على المعرفات والعزل.
