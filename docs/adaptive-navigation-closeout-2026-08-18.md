# إغلاق Adaptive Navigation وSmart Global Command Bar

اكتمل تنفيذ التنقل التكيفي وشريط الأوامر العالمي في Nawa ERP. يحفظ النظام تفضيل المستخدم محلياً بحسب حسابه في إحدى ثلاث حالات: **AUTO** و**EXPANDED** و**COMPACT**. في AUTO يعرض جذر البوابة قائمة موسعة بأسماء الصفحات والمجموعات، بينما تستعمل صفحات العمل Rail مضغوطاً بالأيقونات، ويحافظ المستخدم على خيار تثبيت الوضع الموسع أو العودة للتلقائي.

| جانب التنفيذ | النتيجة |
|---|---|
| التنقل | Rail مضغوط، قائمة موسعة في Portal Overview، وDrawer نصي على الهاتف حتى عند تفضيل COMPACT على سطح المكتب |
| Flyout والوصول | فتح بالنقر أو المرور، تلميحات أسماء، `aria-current` للصفحة النشطة، Escape للإغلاق، ودعم RTL/LTR |
| الرأس | Command Bar يضم البوابة الحالية، مبدل البوابات، البحث، الإنشاء السياقي للحسابات ذات الدور الإداري، Nawa AI، التنبيهات، المؤسسة والحساب |
| البحث | Command Palette يبحث في الصفحات والأدوات؛ وبعد حرفين يبحث خادمياً في منتجات وعملاء وفواتير المؤسسة فقط، وفق اشتراكات inventory وsales النشطة |
| العزل | اختبار تكامل جديد يثبت استبعاد سجلات مؤسسة ثانية وحجب نوع السجل حين لا تكون وحدته مشمولة |

## التحقق

نجح `pnpm check` و`pnpm lint`، واجتازت الحزمة الكاملة **228 اختباراً في 100 ملف**. جرى التحقق بصرياً على سطح المكتب من أوامر الإنتاج وفواتير المبيعات والإعدادات، وعلى الهاتف من أوامر الإنتاج وفواتير المبيعات. لم تسجل السجلات بعد التعديل أخطاء متصفح أو طلبات 4xx/5xx جديدة. أُعيدت محاولة البناء من خط الأساس، لكنه توقف بالرمز 143 أثناء `vite build` نتيجة حد ذاكرة البيئة المعروف، لا خطأ تجميع في المشروع.
