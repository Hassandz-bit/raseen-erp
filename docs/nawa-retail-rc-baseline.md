# Baseline — Release Candidate Pilot

## نقطة البداية

اعتمد التحقق نقطة الاستعادة `486dbe8f` أساساً مستقراً. حالة Git عند البدء أظهرت تعديلاً مقصوداً في `todo.md` فقط لإدراج بنود تدقيق الطيار؛ لم يظهر تعديل وظيفي غير محفوظ.

## الترحيلات

تغطي ملفات SQL الترحيلات من `0000` حتى `0043`. يوجد ملفان باسمين مختلفين يبدأان بالرقم `0037`: `0037_pink_wither` مسجل في Journal ويضيف دور التاجر ونطاق منافذه، و`0037_nawa_retail_entitlement_seed` ترحيل بيانات يدوي غير هدمي لتفعيل إضافة Retail للمؤسسات التي تملك سجلات B2B. لا يسجل Journal الترحيل اليدوي، لكنه طُبّق سابقاً كترحيل بيانات مستقل؛ لا توجد عملية DROP أو تعديل هدمي ولا تعارض في المخطط الناتج.

## نتائج Baseline

| الفحص | النتيجة | الملاحظة |
|---|---|---|
| `pnpm check` | PASS | لا توجد أخطاء TypeScript. |
| `pnpm lint` | PASS مع 12 تحذيراً | كلها unused-vars موروثة خارج نطاق Retail، بلا أخطاء. |
| `pnpm test` | PASS | 76 ملف اختبار و160 اختباراً ناجحاً. |
| `pnpm build` | PASS | اكتمل البناء؛ توجد ملاحظات حجم chunks فقط. |

## قرار المرحلة

خط الأساس صالح لبدء طيار معزول. لا توجد Regression برمجية أو ترحيل هدمي يمنع الانتقال للمرحلة التالية.
