# تقرير الإغلاق النهائي: عمولة التسليم الجزئي

## الحالة التنفيذية

**Executive Status: PASS.** نقطة الأساس هي `1fa21551` بعد تقرير نطاق HR والعمولات. لا تعيد هذه الدفعة تنفيذ نطاق HR أو عمولات البيع والتحصيل أو Self-Service أو الرواتب أو المالية أو وثائق المركبات، ولا تضيف أي ميزة AI.

## المعمارية

كل سجل تسليم مرتبط بفاتورة يكتب أسطره في `distribution_delivery_items`. بعد نجاح الحدث، تنشئ خدمة العمولات قيداً مستقلاً لكل سطر ذي **كمية مسلمة موجبة** و**قيمة تجارية موجبة**. مصدر القيد هو `distribution_delivery_item` مع `deliveryItemId`، وليس `invoiceId` أو `deliveryId` وحدهما؛ لذلك تقبل الفاتورة نفسها تسليمات جزئية لاحقة بينما تمنع إعادة محاولة السطر نفسه.

| بند | السلوك المنفذ |
|---|---|
| أساس الحساب | `deliveredQuantity × (salesInvoiceItem.lineTotal ÷ salesInvoiceItem.quantity)` لكل منتج. |
| التسليم الجزئي | ينشئ عمولة فوراً حتى لو كانت حالة التسليم `partial`. |
| التسليم اللاحق | ينشئ قيود أسطر جديدة فقط، فلا يعيد احتساب التسليم السابق. |
| المنتجات المختلطة | يعالج كل منتج على حدة؛ تجمع النتيجة أسطر المنتجات المسلمة فقط. |
| الكمية المجانية | سطر `lineTotal = 0` ينتج أساساً صفرياً ولا ينشئ إيراداً أو عمولة وهمية. |
| منع تجاوز الكمية | داخل معاملة تسجيل التسليم، يمنع مجموع التسليمات السابقة والجديدة لكل منتج من تجاوز كمية بند الفاتورة. |
| التاريخ | يستخدم كل قيد `deliveredAt`، ولذلك يدخل فترة الرواتب المطابقة لتاريخ ذلك التسليم لا تاريخ اكتمال الفاتورة. |
| الرواتب والمالية | تدخل القيود المؤهلة مرة واحدة في لقطة الرواتب ثم ترحل مع فترة الرواتب فقط؛ لا ينشأ Journal Entry مباشر عند التسليم. |

## عكس المرتجعات

يربط المرتجع بالتسليم والمنتج. يجمع النظام الكمية المسلمة لذلك المنتج في التسليم، ويخصم كميات المرتجعات السابقة، ثم يعكس نسبة لا تتجاوز العمولة الأصلية لأسطر التسليم. يسجل القيد السالب بمصدر `distribution_return_reversal` ومعرف المرتجع، ولا يحذف القيد الأصلي. لذلك يعكس المرتجع الأول القدر المستحق فقط، والمرتجع اللاحق لا يستطيع تجاوز الرصيد المتبقي.

## الترحيلات ونقطة الاستعادة

لا يوجد ترحيل جديد لهذه الدفعة؛ تعتمد على الترحيل السابق `0034_melodic_wallow.sql` الذي أضاف مصدر `deliveries` لقواعد العمولات. نقطة الاستعادة النهائية تسجل بعد حفظ هذا التقرير.
