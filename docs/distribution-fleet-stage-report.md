# تقرير مرحلة التوزيع والأسطول

## الملخص التنفيذي

أُنجزت مرحلة التوزيع والأسطول فوق نواة التجارة والمخزون في Nawa ERP من دون تغيير تصميم الوحدات السابقة. يعتمد التنفيذ على عزل مؤسسي صريح في كل جدول ومسار خادمي، وعلى مركبة مرتبطة بمخزن متنقل فعلي بدلاً من رصيد يدوي. تنتقل الكميات عبر سجل حركات المخزون ودفعات المنتجات وأرصدة المخازن ضمن معاملات ذرية، وتظل الجولات والتحصيلات والتسليمات والمرتجعات والتسويات قابلة للتدقيق.

## المخطط والتدفقات

تضيف المرحلة جداول للمركبات ووثائقها والوقود والصيانة والمناطق والجولات والمحطات وأوامر التحميل وبنودها والتسليمات والتحصيلات والمرتجعات ونفقات الجولة وإقفالها، إضافة إلى أحداث Geofence وسجلات GPS ومفاتيح idempotency. كما أضيفت حقول موقع وأولوية زيارة للعميل، وحقول وزن الكرتون وحجم المنتج اللازمة لقياس السعة.

| المجال | السلوك المنفذ | ضابط الحوكمة |
|---|---|---|
| المركبة | تنشأ مع مخزن متنقل مستقل | رمز ولوحة ومخزن متنقل فريدان داخل المؤسسة |
| التحميل | يمر عبر Draft → Prepared → Approved → Loading → Loaded → Dispatched | FEFO للدفعات النشطة، سعة وزن/حجم، وسياسة تحذير أو منع أو تجاوز مدقق |
| الجولة | محطات عميل مرتبة وربط اختياري بالفاتورة | تحقق المؤسسة والفرع والمنطقة والمركبة ونطاق العضوية |
| التسليم والمرتجع | خصم من مخزون المركبة أو إعادته/عزله | مفاتيح idempotency وحركات مخزون وسجل تدقيق |
| التحصيل | تسوية مرتبطة بالعميل والفاتورة وسعر صرف محفوظ | التحقق من تطابق العميل والفاتورة وعزل المؤسسة |
| الإغلاق | Submitted → Reviewed → Approved → Closed مع Reopen مبرر | حساب فرق النقد وفارق المخزون وسجل تدقيق |
| الأسطول | وثائق ووقود وصيانة وسجل GPS وGeofence | تنبيهات انتهاء الوثيقة والصيانة تضاف فقط إلى تنبيه مالك المنصة |

> لا ينشئ النظام مواقع GPS أو عمليات ميدانية وهمية. يوفّر فقط عقد تخزين وواجهات محكومة لتطبيق سائق أو جهاز تتبع لاحقاً.

## الواجهة والتقارير

أضيف مركز عمليات `/distribution` باللغات العربية والفرنسية والإنجليزية، يقدّم مؤشرات الجولات والمركبات المحملة والتسليمات والتحصيلات والمرتجعات واستغلال السعة. تتضمن الواجهة إنشاءاً سريعاً لمركبة أو منطقة أو جولة، وحالات تحميل وفراغ وخطأ، وتصدير تقرير الملخص إلى Excel متوافق وPDF يدعم اتجاه الواجهة وخط المستند. رُبطت عقدة التوزيع في Nawa Flow بالمخزون والمبيعات والمالية فقط، وتفتح مركز العمليات من دون تعديل البنية الأساسية للخريطة.

## التحقق والقيود

يغطي اختبار التكامل الجديد إنشاء مركبة ومخزن متنقل وتحميل دفعة، والتحقق من عزل مؤسسة أخرى، وحركات `vehicle_load_out` و`vehicle_load_in`، ومنع الإرسال المكرر. وتغطي اختبارات السياسة سعة الحمولة وانتقالات الحالات والصلاحيات والنطاق، بينما يغطي اختبار الواجهة الملخص والفراغ وتصدير Excel.

يبقى تطبيق السائق الميداني، وإرسال المواقع في الخلفية، والتوقيع والصور والمرفقات الفعلية، والتكامل المحاسبي الكامل، نطاقات تالية مقصودة. لا تمثل هذه العناصر نقصاً في عقود المرحلة الحالية، بل تعتمد على قنوات أجهزة وهوية ميدانية لم تُضف بعد.
