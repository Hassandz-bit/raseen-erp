# تحقق مرئي مرحلي لضريبة القيمة المضافة

تم التحقق من شاشة إعدادات الضريبة وسجل فواتير المبيعات على سطح المكتب. ظهرت إعدادات النسبة ووضع السعر وزر الحفظ بصورة واضحة، كما ظهر سجل الفواتير ضمن بوابة التجارة.

أظهر التقاط الصفحة الكاملة على عرض 390px انزياحاً ظاهرياً مرتبطاً بعناصر التخطيط الثابتة أثناء التقاط الصفحة كاملة. بعد التحقق من لقطة نافذة الهاتف الفعلية، ظهرت الشاشة كاملة وقابلة للقراءة من دون انزياح أو تمرير أفقي، مع حقلي النسبة وطريقة عرض السعر وزر الحفظ ضمن عرض الشاشة. أضيفت أيضاً قيود عرض دفاعية إلى حاوية الإعدادات ولوحة الضريبة لمنع تمدد محتوى مستقبلي.
