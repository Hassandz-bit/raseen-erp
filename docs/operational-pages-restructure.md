# إعادة هيكلة صفحات المتابعة التشغيلية

تم تحويل تجربة المتابعة من لوحة واحدة طويلة إلى **مسارات صفحات تشغيلية** مرتبطة بالشريط الجانبي لكل بوابة. تستخدم كل صفحة العقود والاستعلامات الموجودة؛ ولم يُنشأ أي منطق مبيعات أو مخزون أو توزيع موازٍ.

| البوابة | المسارات التشغيلية | نوع المتابعة |
|---|---|---|
| التجارة والمخزون | `/commerce/products`، `/commerce/warehouses`، `/commerce/batches`، `/commerce/sales`، `/commerce/purchases` | جداول قابلة للبحث لكتالوج المنتجات والمخازن والدفعات والفواتير وأوامر الشراء. |
| التوزيع والأسطول | `/distribution/routes`، `/distribution/fleet`، `/distribution/territories`، `/distribution/alerts` | جداول الجولات والمركبات والنطاقات وتنبيهات الامتثال. |
| التصنيع والجودة | `/manufacturing/orders` ومسارات المواد والصرف والمراحل والمخرجات والجودة والتكاليف والتتبع | جدول أوامر مع اختيار أمر إنتاج ثم جدول محور التفاصيل من مساحة الأمر الرسمية. |
| Retail | `/retail/accesses`، `/retail/outlets`، `/retail/users`، `/retail/promotions`، `/retail/orders`، `/retail/returns` | جداول معزولة لعلاقات التجار والمنافذ والعروض والطلبات والإرجاعات. |
| المالية | `/finance/accounts`، `/finance/entries`، `/finance/aging`، `/finance/treasury`، `/finance/reports` | جداول الحسابات والقيود والذمم والخزينة والتقارير. |
| الموارد البشرية | `/hr/employees`، `/hr/attendance`، `/hr/leave`، `/hr/overtime`، `/hr/payroll` | جداول الموظفين والوقت والإجازات والرواتب، مع استمرار حارس الرواتب الخادمي. |

> تظل عمليات الإنشاء والاعتماد والتحويل والإجراءات الحساسة داخل مراكز التشغيل الرسمية المرتبطة بكل صفحة، حتى لا تتجاوز الصفحات الجداول منطق الأعمال أو الصلاحيات.

## التحقق

اجتاز المشروع فحص الأنواع، و**206 اختبارات** ضمن **91 ملف اختبار**. لا توجد أخطاء تدقيق؛ التحذيرات الثمانية المتبقية موروثة في ملفات خادم خارج هذا التغيير.
