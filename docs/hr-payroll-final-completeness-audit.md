# تدقيق الإكمال النهائي للموارد البشرية والرواتب

## نقطة الأساس

نقطة الأساس المثبتة هي **`77d70a4`** (Checkpoint `77d70a44`). يتضمن هذا الأساس بوابة الموظف، صلاحيات HR التفصيلية، وتصدير CSV البنكي. لا تعيد هذه الدفعة بناء هذه الوظائف؛ بل تدققها وتصلح فجوات الدورة الفعلية فقط.

## مصفوفة الميزات الفعلية

| المجال | الحالة | الدليل التشغيلي أو الفجوة |
|---|---|---|
| Employee Master، Employee/User، Departments، Positions، Manager hierarchy | DONE | موظف مستقل، `employee_profiles` بربط مستخدم اختياري ومدير مباشر، وكيانات أقسام ومناصب مع عزل المؤسسة. |
| Contracts وWork Schedules | DONE | عقد بنوع وتواريخ وأساس راتب ومبلغ وعملة وجدول عمل؛ الجدول يدعم الأيام والبداية والنهاية والاستراحة. |
| Attendance وOvertime | PARTIAL | الحضور والساعات الإضافية موجودة ومراجعة، لكن حساب الراتب لا يستنتج الخصم أو الساعات من سجل الحضور ولا يدعم أساس اليوم الشهري كاملاً. |
| Leave وLeave Balances | PARTIAL | الطلب والمدير المباشر وحالاته موجودة؛ لا يظهر تطبيق فعلي لرصيد الإجازة أو خصم الرصيد عند الاعتماد، ولا إلغاء محكوم من الخدمة الذاتية. |
| Payroll periods، calculate، approval، reopen | DONE | حالات وصلاحيات وعكس اعتماد مدقق؛ الحساب مسموح قبل الاعتماد واللقطة تثبت عند الاعتماد. |
| Base، Allowances، Bonuses، Deductions، Gross/Net | PARTIAL | المعادلة الأساسية تعمل، لكن التعديلات غير مقيدة دائماً بالفترة؛ وغياب الموظف لا ينتج غياباً محسوباً رغم وجود حقل. |
| Advances وRecovery | PARTIAL | دورة الطلب/الاعتماد والدفع أساسها موجود؛ الاسترداد يحسب في الرواتب لكنه لا يحدث رصيد السلفة أو حالتها بصورة ذرية بعد إدراج الراتب. |
| Commissions | PARTIAL | قواعد وقيود مصدر فريدة موجودة؛ الحساب لا يقيد القيود بفترة الرواتب ولا يربط تلقائياً بأحداث البيع أو التحصيل الصالحة. |
| Payroll snapshot وPayslips | PARTIAL | لقطة وقسيمة موجودتان عند الاعتماد؛ لا تتوفر شاشة ذاتية لقسيمة الموظف أو تصدير PDF/Print مستقل للقسيمة. |
| Finance posting، payment، idempotency، bank export | DONE | الترحيل والدفع عبر المطابقات، مصادر فريدة، وفترة مدفوعة فقط لتصدير البنك مع التحقق من المرجع والصافي. |
| Employee Self-Service | PARTIAL | الملف والإجازة والسلفة موجودة؛ حضور الموظف وقسائمه غير معروضين في البوابة. |
| Manager Self-Service | PARTIAL | اعتماد إجازة وسلفة للتقارير المباشرة مؤمن خادمياً؛ مراجعة جاهزية حضور الفريق غير متاحة. |
| Reports وExcel/PDF/Print | PARTIAL | دليل الموظفين Excel/Print ومركز HR قائم؛ ينقص سجل رواتب عملي وتقارير حضور وغياب وسلف وعمولات حسب الفرع والقسم. |
| Permissions وData Scope وAudit | PARTIAL | أذونات ذاتية ومدير وHR موجودة وسجل تدقيق واسع؛ حراسة HR التشغيلية ما زالت تعتمد المالك في عدة مسارات، ونطاق الفرع والقسم لا يطبق بصورة موحدة. |
| i18n وRTL/LTR | DONE | مراكز HR والبوابة الذاتية تدعم العربية والفرنسية والإنجليزية والاتجاهين. |

## أولويات الإصلاح المبررة

الأولوية هي رصيد الإجازة، واسترداد السلف بعد الرواتب، وتقييد الحسابات والتعديلات والعمولات بالفترة، ثم تقارير السجل وقسيمة الراتب. لا تشمل المرحلة محرك قوانين دولة أو بصمة أو توظيف أو AI أو إدارة أداء متقدمة.
