# تحديث نطاقات التوزيع والموقع الجغرافي

تم استبدال تسمية **«منطقة جديدة»** بـ **«نطاق توزيع أو منطقة خدمة»** لتوضيح أن السجل يصف مساحة التغطية التشغيلية وليس محلاً جديداً. يتيح النموذج إدخال رمز واسم نطاق الخدمة في حقول أحادية السطر، ثم إضافة نقطة مرجعية اختيارية للخدمة عبر زر استخدام الموقع الحالي أو اختيار نقطة على الخريطة أو إدخال خط العرض والطول يدوياً.

أضيفت حقول `latitude` و`longitude` الاختيارية إلى `distribution_territories` عبر الترحيل `0029_productive_malcolm_colcord.sql`. يرفض الخادم إحداثيات غير مكتملة أو خارج نطاق GPS، ويحفظ في التدقيق أن الموقع التُقط. تبقى إحداثيات النطاق معزولة داخل المؤسسة ولا تعني إنشاء متجر أو فرض تتبع ميداني على السائق.

اجتاز `pnpm check` واختبار واجهة التوزيع واختبار التكامل لحفظ GPS: **ملفان و3 اختبارات ناجحة**.
