# خط أساس معمارية Nawa Portals

## نقطة البداية

نقطة الاستعادة المرجعية قبل التعديل هي `fd350428`. لا يضيف نطاق بوابات Nawa جداول أو ترحيلات أو عقود خادمية جديدة؛ وهو تنظيم للعرض والتنقل فوق المسارات القائمة.

## المسارات القائمة ومكانها المنطقي

| المسار | البوابة المنطقية | القرار |
|---|---|---|
| `/` | بوابات Nawa + Executive Overview | سيعاد تنظيمه إلى بوابات رئيسية مع ملخص تنفيذي منفصل. |
| `/workspace` | مساحة العمل | Nawa AI وNawa Flow فقط، من دون تدفقات تشغيلية مكررة. |
| `/commerce` | التجارة والمخزون | بوابة تشغيلية واحدة تشمل الكتالوج والمبيعات والمشتريات والمخزون. |
| `/manufacturing` | التصنيع والإنتاج | بوابة تشغيلية مستقلة. |
| `/distribution` | التوزيع والأسطول | بوابة تشغيلية مستقلة. |
| `/driver` | تجربة السائق | واجهة دور فرعي مستقلة، لا تدخل القائمة الإدارية العامة. |
| `/retailer` | تجربة التاجر | بوابة خارجية مستقلة Mobile-first. |
| `/b2b-orders` | Nawa Retail للمورد | مركز المورد الإداري، منفصل عن التاجر. |
| `/finance` | المالية والمحاسبة | بوابة تشغيلية مستقلة. |
| `/hr` | الموارد البشرية والرواتب | بوابة تشغيلية مستقلة. |
| `/self-service` | خدمة الموظف الذاتية | واجهة دور فرعي مستقلة. |
| `/modules` | الوحدات والاشتراكات | مركز إدارة الإضافات والتفعيل. |
| `/settings` | الإدارة والإعدادات | مركز الإعدادات والملخصات الإدارية. |

## الفجوة القائمة

يوجد غلافان لتنقل عام: `Home.tsx` و`DashboardLayout.tsx`. يكرر كلاهما قائمة طويلة على مستوى المنصة، بينما تستخدم معظم الوحدات `DashboardLayout`. كما يجمع `/workspace` التحليل الذكي وFlow وعمليات وملخصات عامة، وهو ما يتعارض مع تعريفه الجديد كمساحة فهم وتحليل.

## الحدود غير القابلة للتغيير

يبقى حارس الاشتراك والصلاحيات في العقود الخادمية ومسارات الوحدات. لا تمنح البطاقة المرئية أو رابط التنقل أي وصول. تبقى تجربة التاجر والسائق والخدمة الذاتية مستقلة بسبب اختلاف الدور ونطاق البيانات.
