# إغلاق طيار Nawa Retail

## النتيجة

أُغلق نطاق الطيار على نقطة الاستعادة `51795d8f` مع بوابة B2B مغلقة متعددة الموردين. لا يكشف النظام للتاجر كلفة المورد أو الهامش أو المخزون الداخلي أو المؤسسات غير المرتبطة به.

| موضوع التشغيل | الإجراء |
|---|---|
| تفعيل المورد | فعّل إضافة `nawa_retail` للمؤسسة، ثم امنح صلاحية Retail لمالك أو مدير مفوض. |
| ربط تاجر | أنشئ Business Party، ثم علاقة دعوة أو وصول؛ لا يوجد تسجيل ذاتي عام. |
| إضافة مستخدم | من مركز المورد، ابحث بالبريد الدقيق لحساب موجود فقط واختر الدور. |
| إضافة منفذ | أنشئ outlet للمشتري واضبط العنوان والموقع الاختياري؛ سيختاره المشتري عند checkout. |
| سياسة الإفصاح | اضبط catalog/prices/promotions/documents/debt/tracking/returns لكل علاقة، ثم تحقق من حالة التاجر. |
| العروض | أنشئ العرض من العقد الإداري القائم، وحدد نافذته وهدفه؛ يظهر فقط للتاجر المستهدف بعد الحل الخادمي. |
| الإرجاع | طلب الإرجاع يسجل للمراجعة فقط. اعتماد المورد لا ينشئ حركة مخزون أو أثر مالي تلقائياً. |

## أدلة التحقق

| الفحص | النتيجة |
|---|---|
| فحص الأنواع | PASS |
| Vitest | 76 ملفاً، 160 اختباراً ناجحاً |
| Lint | PASS بلا أخطاء؛ 12 تحذيراً موروثاً خارج Retail |
| Build | PASS؛ تحذير حجم chunks فقط |
| معاينة الهاتف | مركز المورد ظاهر ومتجاوب؛ بوابة Retail عُرضت في حالة غير مصادق عليها. الانزياح المرئي في أداة الالتقاط موثق، بينما قياس DOM أكد عدم وجود overflow في الصفحة. |

## حدود مقصودة

لا ينفذ طلب الإرجاع حركة مخزون أو إشعاراً مالياً تلقائياً. لا توجد إشارة حية مدعاة لتتبع فعلي من حساب تاجر في هذا الإغلاق؛ يبقى ذلك إجراء قبول تشغيلي ببيانات الطيار الحقيقية.
