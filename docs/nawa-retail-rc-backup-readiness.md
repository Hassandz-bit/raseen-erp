# جاهزية العزل والنسخ الاحتياطي — RC Pilot

## نتائج الحماية

نجحت حزمة الحماية المستهدفة في 15 اختباراً عبر ستة ملفات. تغطي النتائج عزل المؤسسة في الفروع والمخزون والفواتير، حارس مالك المؤسسة، وعزل Retail بحسب علاقة الوصول. لا يقبل أي عقد Retail معرف مؤسسة خاماً من واجهة التاجر.

## قابلية الاستعادة

لا يمكن تحديد ما إذا كان حساب المشروع متأثراً بتغيير خدمات Manus من داخل الكود أو من موقع المشروع؛ مصدر الحقيقة هو الإشعار داخل التطبيق والبريد الخاص بالحساب. إذا كان الحساب متأثراً، يجب إنشاء **Task Data Backup** يضم هذا المشروع قبل الموعد المبين في الإشعار الرسمي، ثم الاحتفاظ بحزمة التصدير كاملة دون تعديل الاسم أو المحتوى.

| بند | حالة الطيار | الإجراء المطلوب عند التأثر |
|---|---|---|
| الشيفرة والترحيلات | PASS | تدخل ضمن Task Data Backup. |
| قاعدة بيانات Retail وERP | PASS | تدخل ضمن Task Data Backup؛ لا يكفي تنزيل الشيفرة وحده. |
| الأسرار والإعدادات والملفات | PASS من جهة النطاق | تحقق من وجودها ضمن الحزمة عند التصدير. |
| بيانات ما بعد اللقطة | PARTIAL مقصود | اللقطة ليست مزامنة؛ صدّر لقطة أحدث قبل أي توقف أو استعادة. |
| الاستعادة | PARTIAL تشغيلياً | لا تُجرّب استعادة حساب فعلي في طيار؛ الاستعادة إجراء حسابي يتم مرة واحدة. |

## إجراء قبول قبل الطيار الفعلي

ينفذ مالك الحساب فقط عملية تصدير Task Data من صفحة النسخ الاحتياطي الرسمية، ويتحقق من وجود الحزمة في الوجهة المختارة. لا ينفذ الاختبار أي تعديل، حذف، استعادة، أو محاولة تصدير لحساب المستخدم.
