# تقرير بوابة الموظف والصلاحيات وتصدير البنك

## ما تم تنفيذه

أضيف المسار `/self-service` كبوابة موظف ذاتية معزولة. لا تستخرج البوابة ملفاً عاماً للموظفين؛ بل تحلّ المستخدم الحالي إلى `employee_profiles.userId` داخل المؤسسة الحالية، وتعرض ملفه وطلبات إجازاته وسلفه فقط. يمكنه إرسال طلب إجازة أو سلفة بحالة `submitted`، ثم تظهر الحالة ضمن سجله الشخصي.

أضيفت سياسة HR تفصيلية بالأذونات `hr.self.*` و`hr.leave.approve_team` و`hr.advance.approve_team` و`hr.payroll.export_bank`. يقيّد اعتماد المدير المباشر نفسه بالموظفين الذين يشير `managerEmployeeId` في ملفاتهم إلى الموظف المرتبط بحسابه. أما إدارة الرواتب والملف البنكي فتبقى خارج هذه الصلاحيات ما لم يوجد تفويض صريح.

أضيف تصدير CSV بنكي عام لفترة رواتب **مدفوعة** فقط. يصدّر اسم المستفيد ومرجع الحساب والمبلغ والعملة ومرجع عملية الرواتب، ويستبعد الصفوف من دون مرجع حساب أو بصافي غير موجب. يظهر زر التنزيل في تبويب الرواتب فقط عند وجود فترة مدفوعة وصلاحية التصدير.

## الضوابط والتحقق

| بند التحقق | النتيجة |
|---|---|
| ترحيل قاعدة البيانات `0028` | مطبق بنجاح؛ يضيف حالات `submitted` و`rejected` لسلف الموظفين. |
| عزل بوابة الموظف | حلّ المستخدم إلى ملفه داخل المؤسسة فقط؛ ويُرفض أي حساب بلا ملف نشط. |
| نطاق المدير المباشر | تحقق خادمي بأن الموظف تابع مباشر للمدير قبل قرار الإجازة أو السلفة. |
| كشف البنك | لا يُنشأ قبل دفع الفترة، ولا يضم الحسابات الناقصة أو الصافي غير الموجب. |
| الاختبارات | `pnpm test`: **63 ملف اختبار و129 اختباراً ناجحاً**. |
| الجودة | `pnpm check` و`pnpm lint` و`pnpm build` ناجحة؛ تحذير حجم حزمة الواجهة غير مانع. |
| التحقق البصري | مراجعة بوابة الموظف ومركز HR بالعربية، مع RTL وسلامة حقول الطلبات. |
