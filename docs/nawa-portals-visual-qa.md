# مراجعة بصرية — Nawa Portals

## التحقق

تمت معاينة صفحة البوابات والملخص التنفيذي ومساحة العمل والتجارة ومركز المورد على سطح المكتب، ثم صفحة البوابات ومساحة العمل والتجارة ومركز المورد عند عرض هاتف `375×812`.

| السطح | النتيجة | الملاحظة |
|---|---|---|
| صفحة البوابات | PASS | بطاقات البوابات مرتبة، شارة الحالة مرئية، والبطاقات تتحول إلى عمود واحد قابل للتمرير على الهاتف. |
| الملخص التنفيذي | PASS | مستقل عن صفحة البوابات، ويعمل ضمن الغلاف الموحد مع روابط نحو الوحدات الفعلية. |
| مساحة العمل | PASS | تعرض Nawa AI وNawa Flow فقط؛ لا توجد بطاقات ملخصات أو إنشاء تشغيلي مكرر. |
| التجارة والمخزون | PASS | يظهر سياق البوابة والتنقل المحلي، ونموذج إضافة المنتج متجاوب في الهاتف. |
| مركز المورد Retail | PASS | أصبح ضمن الرأس والتنقل المحلي للبوابة، ويظل محتوى الإدارة متجاوباً على الهاتف. |
| الرأس المشترك | PASS | يعرض البوابة وBreadcrumbs ومبدّل البوابات؛ الحقل الجاهز للبحث مخفي على الهاتف لتجنب ازدحام الشريط. |

لا يوجد تداخل أو overflow مرئي في اللقطات الحالية. ستبقى بوابة التاجر `/retailer` والسائق والخدمة الذاتية خارج الغلاف الإداري عمداً بسبب اختلاف الدور وتجربة الاستخدام.
