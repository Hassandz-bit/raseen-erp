# Nawa ERP — معمارية المالية والمحاسبة

## نقطة الأساس والنطاق

> **Base SHA المعتمد: `83ab085`** — يتضمن إغلاق مراجعة التصنيع، وحراسة العمليات والواجهات، واختبارات التتبّع والتكلفة. لا يُعاد تنفيذ التصنيع أو التجارة والمخزون أو التوزيع أو تطبيق السائق أو B2B في هذه المرحلة.

تُبنى المالية كطبقة محاسبية تستهلك أحداث الوحدات التشغيلية الحقيقية ولا تستبدل مستنداتها. تحتفظ الوثيقة التشغيلية بمالك دورة العمل، بينما ينتج عنها قيد محاسبي مدقق واحد وفق قاعدة ترحيل وإعدادات مطابقة حسابات المؤسسة.

| الطبقة | المسؤولية | قاعدة الحوكمة |
|---|---|---|
| المستند التشغيلي | فاتورة بيع أو شراء، تحصيل، حركة مخزون أو إنتاج | لا يُنشئ المستخدم قيوداً يدوية للعمليات العادية |
| قاعدة الترحيل | تحدد الدائن والمدين والمطابقات | لا تحتوي معرّفات حسابات ثابتة في الكود |
| القيد اليومي | إثبات مالي مرجعي متوازن | المدين يساوي الدائن قبل الترحيل |
| الدفتر والتقرير | قراءة آثار القيود والفترات | يعزل دائماً بـ `organizationId` وصلاحية المالية |

## نموذج القيود والضوابط

يعتمد القيد حالاته **Draft → Posted → Reversed**؛ ولا يُعدل القيد المرحّل مباشرة. التصحيح يتم بقيد عكسي أو قيد تصحيحي مرجعي مع سجل تدقيق. يُرفض أي ترحيل عندما تكون الفترة مغلقة أو محجوبة، أو عندما يكون القيد غير متوازن، أو تكون مطابقة الحساب غير موجودة أو خارج المؤسسة.

| الحدث | الأثر المحاسبي المستهدف | حالة الربط |
|---|---|---|
| فاتورة مبيعات مؤكدة | ذمم مدينة/نقدية ← إيراد ومبالغ ضريبية عند الإعداد | Posting Rule من دون ازدواجية |
| فاتورة/استلام مشتريات | مخزون أو مصروف ← ذمم دائنة | Posting Rule من دون ازدواجية |
| تحصيل معتمد قائم | نقدية/بنك ← ذمم مدينة | إعادة استخدام التحصيلات القائمة |
| سحب مواد تصنيع | WIP ← مخزون مواد خام | مرجعية لمصروفات الإنتاج الحالية |
| مخرج تصنيع | مخزون منتج نهائي ← WIP | لا إعادة احتساب تكلفة التصنيع |
| تسوية/تلف مخزون | حساب تسوية أو تلف ← مخزون | وفق سياسة التكلفة الحالية |

## الحدود المتعمدة لهذه المرحلة

يبقى قالب دليل الحسابات **عاماً وغير ملزم قانونياً لأي دولة**. تكون الضرائب قابلة للإعداد ولا تُفترض نسب قانونية. يظل تكامل الرواتب في حدود القيد المحاسبي للرواتب المعتمدة فقط، من دون توسيع دورة الموارد البشرية. تظل مراكز التكلفة والعملات المتعددة جاهزية بنيوية حيث لا يكتمل ربطها بعد.
