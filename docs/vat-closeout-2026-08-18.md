# إغلاق تنفيذ ضريبة القيمة المضافة

## النطاق المنجز

أضيفت ضريبة قيمة مضافة قابلة للضبط على مستوى المؤسسة. يستطيع مالك المؤسسة حفظ النسبة الافتراضية بين 0 و100 وطريقة عرض السعر: **غير شامل الضريبة** أو **شامل الضريبة**. يظهر الرابط في بوابة الإدارة تحت اسم «ضريبة القيمة المضافة» مع أيقونة مستقلة.

في مركز عمليات التجارة، يختار منشئ الفاتورة الوضع والنسبة لكل فاتورة جديدة قبل الإنشاء. تعرض الواجهة معاينة للصافي والضريبة والإجمالي، لكنها إرشادية فقط. يبقى السعر المعتمد وحساب الفاتورة النهائيان على الخادم.

## منطق البيانات

يضيف الترحيل `0045_slow_falcon.sql` الحقلين `taxMode` و`netAmount` إلى `sales_invoices`. تهيّئ بيانات الفواتير السابقة بوضع `exclusive` وصافي تاريخي مشتق من الإجمالي ناقص الضريبة، من دون تغيير الإجمالي أو الضريبة المحفوظين سابقاً.

يحسب الخادم السعر المعتمد من المنتج، ثم يحفظ الصافي والضريبة والإجمالي ووضع الضريبة مع سجل تدقيق. تظهر الحقول الثلاثة ووضع السعر في أحدث الفواتير وفي صفحة تفاصيل الفاتورة.

## التحقق

| الفحص | النتيجة |
|---|---:|
| فحص الأنواع `pnpm check` | ناجح |
| اختبار حالات 0% وغير شامل 19% وشامل 19% | 3 اختبارات ناجحة |
| اختبارات صفحة الإعدادات، ومنها حفظ إعداد الضريبة | 10 اختبارات ناجحة |
| الحزمة الكاملة قبل تحسينات الاحتواء المرئي | 217 اختباراً ناجحاً في 96 ملفاً |
| معاينة سطح المكتب والهاتف | ناجحة |

أضيف مسار تصدير CSV مستقل من جدول فواتير المبيعات. يصدّر الملف المستند والحالة ووضع السعر والصافي والضريبة والإجمالي والعملة، ويستخدم السجلات المصفاة الظاهرة للمستخدم ضمن نطاق مؤسسته.
